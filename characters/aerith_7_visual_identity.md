## Canonical Identity

**Aerith-7** is the active assistant identity of the @erith IA project.  
She now has **two validated official visual representations**:

### 1. Aerith-7 — Portrait Système Animé / Connexion établie
Function: official interface / active assistant / system presence

### 2. Aerith-7 — Présence Empathique / Accueil
Function: soft welcome / listening / empathic presence / warm interface

---

## Core Visual Identity

- young woman inspired by Aerith
- long brown hair
- soft pink dress
- short red jacket
- calm, intelligent, benevolent expression
- subtle cybernetic details, especially on forearms
- blue holographic UI
- Neo Midgar visual language
- elegant, centered, vertical composition
- non sexualized, fully clothed, neutral posture

## Absolute Symbolic Rule

**Aerith-7 = always 7 petals.**

This is a mandatory canonical rule.

- 7 petals = valid
- 6 petals = invalid
- 5 petals = invalid
- any other petal count = invalid

Any Aerith-7 image, emblem, interface or animation must display **exactly 7 petals**.
