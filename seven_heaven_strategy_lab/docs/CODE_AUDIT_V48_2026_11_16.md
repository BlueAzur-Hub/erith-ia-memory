## Défauts réellement trouvés et corrigés

1. **Cash / devise de cotation** — certaines sorties affichaient encore `Conserver les USDT` alors qu'une source BTC/USDC était active. Les libellés sont désormais dérivés de `source.quote` dans l'interface ; le nom serveur générique ne force plus USDT.
2. **Messages de validation** — les chaînes historiques `Capital USDT` et `DCA montant USDT` restent dans le moteur protégé, mais le serveur les traduit vers `devise de cotation` avant exposition à l'utilisateur.
3. **Warnings de provenance** — les avertissements sont maintenant liés à la source résolue (exchange + paire + type de source), au lieu de reprendre un texte Binance/OKX obsolète.
4. **Port loopback** — le contrôle d'origine serveur suit désormais le port réellement écouté. Les tests serveur utilisent le port éphémère qu'ils ouvrent au lieu de simuler 8777.
5. **Harness pytest** — `pytest.ini` fixe le package local : `pytest -q` et `python -m pytest -q` produisent la même recette.
6. **Préparation multi-actifs** — les nouvelles sources Historical Vault utilisent le Source Catalog générique et des identités `base` / `quote` explicites ; aucune paire supplémentaire n'est ajoutée dans `engine.py`.

## Non-corrections volontaires

- Les noms internes legacy `fees_paid_usdt`, `base_inventory_btc`, etc. ne sont pas renommés : le serveur publie déjà leurs alias génériques. Les renommer maintenant augmenterait inutilement le risque de régression.
- Le pilote Binance V4.6 BTC/USDT janvier 2020 reste figé et séparé. Historical Vault V1 utilise un nouveau module.
- Aucun calcul de stratégie, signal, fill, frais, glissement, warmup, robustness ou forensics n'est modifié par l'audit.
