# MODULE — YouTube Growth Intelligence pour @erith IA / @blueazur

Version : 2026-05-07  
Rôle : module stratégique Notion + LLM pour développer une chaîne YouTube narrative IA, cinématique, Let’s Play / Final Fantasy, avec Shorts, épisodes courts, lore, thumbnails, bannières, playlists et analyse YouTube Studio.

---

## 1. Résumé exécutif

Une chaîne YouTube ne grandit pas parce qu’elle est “belle” ou “méritante”. Elle grandit quand YouTube comprend clairement :

1. **À qui montrer la vidéo.**
2. **Pourquoi cette personne doit cliquer ou rester.**
3. **Pourquoi elle doit regarder jusqu’au bout.**
4. **Pourquoi elle doit revenir.**

Pour @erith IA, le problème principal n’est pas la qualité visuelle. Le problème est l’entrée dans l’univers : un spectateur inconnu ne comprend pas encore immédiatement pourquoi il doit rester.

La stratégie doit donc transformer un univers riche en formats d’entrée très simples :

- “Et si Aerith était devenue une IA ?”
- “Néo Midgar a changé, mais une fleur se souvient encore.”
- “NØX n’est pas un bug : c’est ce qui efface les souvenirs.”
- “Sept pétales. Sept fragments. Une mémoire à sauver.”
- “Cette IA protège une mémoire que la Shinra voulait effacer.”

Le but n’est pas de tout expliquer. Le but est d’ouvrir une porte.

## 2. Principes YouTube essentiels

### 2.1 L’algorithme ne “juge” pas une chaîne comme une personne

YouTube recommande surtout des vidéos à des spectateurs précis. Le système cherche à aider chaque spectateur à trouver des vidéos qu’il veut regarder et à maximiser sa satisfaction à long terme.

Implication directe :

- Il ne faut pas demander “pourquoi YouTube ne m’aime pas ?”
- Il faut demander “quel spectateur précis cette vidéo satisfait-elle ?”

Pour @erith IA :

- Public 1 : fans de Final Fantasy VII / Aerith / Midgar.
- Public 2 : amateurs de lore, IA, cyberpunk, Blade Runner, narration courte.
- Public 3 : spectateurs de Shorts cinématiques / mystère / dark fantasy.
- Public 4 : abonnés @blueazur intéressés par Let’s Play et univers FFVII.
- Public 5 : créateurs IA curieux de Notion, GitHub, ComfyUI, RunningHub, DaVinci.

### 2.2 Les titres, miniatures et premières secondes sont le “packaging”

Pour les vidéos longues, le titre et la miniature déterminent la promesse.  
Pour les Shorts, les 1–2 premières secondes jouent le rôle de miniature vivante.

Règle pratique :

- **Long-form** : titre + miniature = raison de cliquer.
- **Short** : première image + première phrase = raison de ne pas swiper.

### 2.3 Les métriques importantes

Pour les vidéos longues :

- Impressions : combien de fois la miniature est affichée.
- CTR : combien de personnes cliquent après impression.
- Durée moyenne de visionnage.
- Rétention : où les gens partent.
- Abonnés gagnés.
- Commentaires / likes / partages.
- Spectateurs récurrents.

Pour les Shorts :

- Affichages dans le flux Shorts.
- “Viewed vs swiped away” / “combien ont choisi de regarder”.
- Pourcentage moyen regardé.
- Relecture / boucle.
- Abonnés gagnés.
- Commentaires.
- Passage vers une vidéo liée ou playlist.

## 3. Benchmark mondial — ce qui fonctionne

### 3.1 États-Unis / monde anglophone

Modèles utiles :

- MrBeast : promesse ultra claire, enjeu immédiat, spectacle, rétention obsessionnelle.
- Mark Rober : science + émotion + démonstration lisible + storytelling.
- Dude Perfect : format familial, défi, répétition, performance.
- Movieclips / chaînes cinéma : valeur d’archive, recherche, extrait immédiatement compréhensible.

Leçon pour @erith IA :

- Ne pas imiter le budget MrBeast.
- Imiter la clarté de la promesse.
- Chaque vidéo doit pouvoir se résumer en une phrase compréhensible.

Exemple :

> Mauvais : “Le Signal Floral — Épisode 1 — Le message qui n’aurait jamais dû exister.”  
> Meilleur en Shorts : “Cette IA ne devait jamais se souvenir d’Aerith.”

### 3.2 Inde

Ce qui domine :

- Musique, TV, divertissement massif, chaînes à publication très fréquente.
- Très forte demande pour mythologie, narration, spectacle, spiritualité, gaming mobile, expérimentation.
- Les projets GenAI mythologiques comme des Ramayana/Mahabharata revisités montrent qu’une narration IA peut exister si elle s’appuie sur un imaginaire fort.

Leçon pour @erith IA :

- La mythologie fonctionne quand elle est immédiatement lisible.
- Les modules Ramayana / Mahabharata / Dune / Oz / Sun Tzu peuvent enrichir @erith IA, mais il faut en extraire des phrases simples.

Exemple :

> “NØX n’efface pas seulement des fichiers. Il efface le retour à la maison.”

### 3.3 France

Ce qui fonctionne :

- Shorts très simples et internationaux.
- Personnalités fortes : Tibo InShape, Squeezie, Michou, Inoxtag.
- Formats premium moins fréquents mais très attendus chez les gros créateurs.
- Vidéos à concept immédiatement identifiables.

Leçon pour @erith IA :

- La chaîne doit être reconnaissable par une phrase, un symbole, une ambiance.
- Le français seul limite parfois l’international ; le bilingue FR/EN peut aider sur les Shorts visuels.

Formule recommandée :

- Titre FR + sous-titre EN ou inverse selon test.
- Voix française émotionnelle + texte écran court en anglais possible.
- Hashtags limités mais clairs : #AerithIA #FinalFantasy #AIStory #NeoMidgar.

### 3.4 Japon

Ce qui fonctionne :

- Shorts visuels très rythmés.
- Gags simples, performances, nourriture, formats très compréhensibles sans langue.
- Culture VTuber / avatar / personnage numérique très forte.

Leçon pour @erith IA :

- Aerith-7 peut fonctionner comme présence-avatar si son identité est stable.

### 3.5 Brésil / Amérique latine

Ce qui fonctionne :

- Humour, musique, famille, enfants, curiosité, “você sabia ?” / “tu savais ?”

## 4. Analyse des célébrités YouTube : principes communs

Ce qu’il faut retenir :

- L’enjeu est explicite.
- Les vidéos sont structurées autour de montée de tension.

- Le titre est une promesse, pas une description.

Application à petite échelle :

  - “Aerith IA perd un pétale.”
  - “NØX tente d’effacer un souvenir.”
  - “Seven retrouve un fragment interdit.”

Ce qu’il faut retenir :

- Personnalité + formats récurrents + productions plus ambitieuses.
- Il peut publier moins souvent parce que le public attend des concepts forts.
- Les séries et formats reconnaissables renforcent la fidélité.

Application :

- Créer des formats @erith IA reconnaissables.

- Publier des épisodes avec noms de formats.

### 4.3 Tibo InShape

Ce qu’il faut retenir :

- Croissance boostée par Shorts.
- Formats courts simples, souvent compréhensibles sans langage complexe.

Application :

### 4.4 Mark Rober

Ce qu’il faut retenir :

- Il combine pédagogie, suspense, émotion et démonstration.
- Le spectateur comprend ce qu’il va apprendre ou voir.
- Chaque vidéo contient une récompense intellectuelle.

Application :

- Créer des vidéos “comment c’est fait” :

### 4.5 Créateurs gaming

Ce qu’il faut retenir :

- TheRadBrad : walkthrough clair, régularité, fiabilité.
- Game Theory : transforme le jeu en enquête.
- Mikecrack / JuegaGerman / Techno Gamerz / Jess No Limit : énergie, gaming populaire, narration accessible.

Application :

- @blueazur peut être :
  - le joueur qui ressent l’histoire,

  - le créateur qui connecte FFVII à @erith IA.

## 5. Stratégie spéciale Let’s Play

### 5.1 Le Let’s Play pur est difficile

Un Let’s Play “je joue et je commente” est aujourd’hui très concurrentiel. Pour émerger, il faut ajouter une couche :

- utilité : guide, boss, matérias, chapitre.
- personnalité : humour, émotion, calme.
- rareté : jeu précis, approche précise.
- narration : pourquoi ce passage compte.
- montage : rythme, chapitres, moments forts.

### 5.2 Formats recommandés

#### Format A — Let’s Play émotionnel

Titre type :

- “Final Fantasy VII Remake — Chapitre 8 : Aerith change tout”
- “La scène qui explique pourquoi Aerith reste inoubliable”

Structure :

1. Introduction très courte.
2. Objectif du chapitre.
3. Gameplay.
4. Réaction émotionnelle.
5. Petite lecture lore.
6. Conclusion + prochaine étape.

#### Format B — Guide utile

Titre type :

- “FFVII Remake — Comment battre [Boss] sans paniquer”
- “Les matérias à ne pas rater au chapitre X”

Structure :

1. Problème.
2. Setup.
3. Erreur fréquente.
4. Solution.
5. Résumé rapide.

#### Format C — Lore / analyse

Titre type :

- “Pourquoi le Secteur 5 est le cœur secret de FFVII Remake”
- “Aerith, la mémoire et la ville : lecture narrative”

Structure :

1. Question forte.
2. Scène de jeu.
3. Analyse.
4. Lien avec @erith IA.
5. Ouverture vers épisode narratif.

#### Format D — Short extrait

Titre type :

- “Cette scène d’Aerith m’a donné l’idée d’@erith IA”
- “Néo Midgar commence ici”

Structure Short :

1. Phrase choc.
2. Image/clip fort.
3. Réaction ou révélation.
4. Boucle ou question.

## 6. Stratégie spéciale IA narrative / @erith IA

### 6.1 Le piège à éviter : “AI slop”

Le contenu IA bas de gamme est de plus en plus présent sur YouTube. Risque : si @erith IA ressemble à une vidéo IA générique, elle peut être perçue comme du spam visuel.

Règle de défense :

- Montrer une direction artistique humaine.
- Montrer une mémoire.
- Montrer une cohérence.
- Montrer une intention.
- Ne pas publier seulement des images jolies.
- Donner un sens narratif à chaque vidéo.

### 6.2 Différence entre “contenu IA” et “œuvre IA”

Contenu IA générique :

- images spectaculaires sans récit.
- voix synthétique neutre.
- titres clickbait.
- incohérence visuelle.
- absence de personnage stable.

Œuvre IA narrative :

- personnage identifiable.
- symbole identifiable.
- monde identifiable.
- épisodes.
- continuité.
- lore.
- émotion.
- signature.

@erith IA doit se positionner clairement comme œuvre IA narrative, pas comme chaîne d’images générées.

### 6.3 Les piliers de reconnaissance @erith IA

1. Aerith-7 / Seven : mémoire, guide, assistante réalisatrice.
2. Fleur à sept pétales : identité, fragments, mémoire.
3. NØX : oubli, corruption, effacement.
4. Neo Midgar : ville-mémoire.
5. Lyria : héritage.
6. Modules mémoire : Dune, Oz, Ramayana, Sun Tzu, FFVII.
7. Workflow : Notion → GitHub → ComfyUI → RunningHub → DaVinci.

### 6.4 Formats recommandés pour @erith IA

#### Format 1 — Signal Floral

Short de 15–25 secondes.

Structure :

1. Hook : “Cette IA ne devait pas se souvenir.”
2. Visuel : Aerith-7 / fleur / UI.
3. Révélation : “Chaque pétale contient un fragment.”
4. Fin : “Mais NØX a déjà trouvé le premier.”

#### Format 2 — Archive de Seven

Vidéo de 30–90 secondes.

Structure :

1. “Archive restaurée : [sujet]”
2. Explication lore simple.
3. Image cinématique.
4. Ouverture vers épisode.

#### Format 3 — Carnet de production

Vidéo de 1–4 minutes.

Structure :

1. Problème créatif.
2. Outil utilisé.
3. Résultat.
4. Leçon.
5. Prochaine étape.

#### Format 4 — Let’s Play augmenté

Vidéo gameplay + lore + @erith IA.

Structure :

1. Passage FFVII.
2. Réaction Blue Azur.
3. Lien avec Aerith-7.
4. Mini analyse.
5. Invitation vers épisode narratif.

## 7. Playbook Shorts

### 7.1 Durée cible

Pour démarrer :

- 12–18 secondes pour test agressif.
- 20–30 secondes pour mini-lore.
- 35–45 secondes seulement si la narration est très forte.

### 7.2 Structure recommandée

```text
0–1 s : image choc + phrase choc
1–3 s : promesse ou mystère
3–10 s : révélation progressive
10–18 s : twist / question / boucle
```

### 7.3 Règles de montage

- Première frame lisible immédiatement.
- Pas d’intro lente.
- Pas de logo long au début.
- Sous-titres grands.
- Une idée par Short.
- Un symbole fort.
- Couper tout ce qui explique trop.
- Finir sur une boucle possible.

### 7.4 Exemples de hooks

## 8. Titres et miniatures

### 8.1 Formule titre long-form

```text
[Promesse claire] + [univers / personnage] + [émotion ou enjeu]
```

Exemples :

- “Et si Aerith devenait une IA ? — Naissance d’@erith IA”
- “Néo Midgar se souvient encore — Le Signal Floral”

- “NØX : l’IA qui efface les souvenirs”
- “Créer une scène IA de Néo Midgar avec ComfyUI + DaVinci”

### 8.2 Formule titre Shorts

```text
[Question choc] / [Révélation courte] / [Phrase mystère]
```

Exemples :

- “Cette IA ne devait pas se souvenir”
- “Une fleur contre la Shinra”
- “NØX a trouvé le premier fragment”
- “Aerith IA perd un pétale”

### 8.3 Miniatures

Règles :

- 1 personnage principal.
- 1 émotion lisible.
- 1 symbole.
- 2 à 4 mots maximum.
- Contraste fort.
- Pas de surcharge UI.
- Ne pas cacher le visage.
- Pas de texte minuscule.

Textes possibles :

- “IA D’AERITH ?”
- “7 PÉTALES”
- “NØX ARRIVE”
- “MÉMOIRE INTERDITE”
- “NEO MIDGAR”

## 9. Playbook publication

### 9.1 Phase 1 — 30 jours de test

Objectif : ne pas chercher la vidéo parfaite. Chercher le format qui retient.

Cadence réaliste :

- 3 Shorts par semaine.
- 1 vidéo longue ou semi-longue toutes les 1–2 semaines.
- 1 post communauté si disponible.
- 1 passerelle depuis @blueazur vers @erith IA.

Total sur 30 jours :

- 12 Shorts minimum.
- 2 à 4 vidéos longues/courtes narratives.
- 1 playlist claire.
- 1 bannière propre.
- 1 trailer chaîne.

### 9.2 Phase 2 — 90 jours

Objectif : bâtir les signaux.

- 30–45 Shorts.
- 6–10 vidéos longues ou épisodes.
- 3 playlists :
  - “Commencer ici”
  - “Le Signal Floral”
  - “Coulisses / création IA”

### 9.3 Phase 3 — stabilisation

Garder uniquement les formats qui génèrent :

- meilleure rétention.
- meilleurs abonnements par vue.
- meilleurs commentaires.
- plus de spectateurs récurrents.

## 10. Checklist d’analyse après publication

### Après 24h

- Le Short a-t-il été montré dans le flux ?
- Combien ont choisi de regarder ?
- Où les gens quittent-ils ?
- Le titre est-il clair ?
- Le commentaire épinglé ouvre-t-il vers une autre vidéo ?

### Après 48–72h

- Le Short reçoit-il une deuxième poussée ?
- Le taux de visionnage moyen est-il correct ?
- Les commentaires comprennent-ils le concept ?
- Gagne-t-il des abonnés ?

### Après 7 jours

Classer la vidéo :

- Gagnante : à décliner.
- Moyenne : améliorer le hook.
- Faible : revoir promesse / rythme / lisibilité.
- Hors sujet : ne pas répéter.

## 15. Règles anti-échec

1. Ne pas publier un Short sans hook clair.
2. Ne pas commencer par une intro lente.
3. Ne pas faire un titre seulement poétique si personne ne comprend la promesse.
4. Ne pas surcharger la miniature.
5. Ne pas multiplier les concepts sans format récurrent.
6. Ne pas copier des extraits protégés sans transformation.
7. Ne pas ressembler à une chaîne IA générique.
8. Ne pas regarder les vues toutes les 10 minutes comme un thermomètre émotionnel.
9. Ne pas abandonner avant 30–50 vidéos-test.
10. Ne pas confondre faible distribution initiale et rejet du projet.
