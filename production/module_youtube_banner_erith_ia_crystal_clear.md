- pas de fond noir final ;

- pas de faux transparent.

## Ce qui est valide

Un fichier valide est :

- un PNG 2048 × 1152 ;
- en RGBA ;
- avec un alpha réel ;
- avec l’artwork centré ;
- avec le logo / texte / personnage / symbole dans la zone safe ;
- avec beaucoup d’espace transparent autour ;
- uploadable directement sur YouTube.

Nom canonique :

`ERITH_IA_BANNER_FINAL_SAFE_TRANSPARENT_RGBA_2048x1152.png`

---

## Ce qui n’est PAS valide

Ne pas considérer comme fichier final :

- une version sur fond blanc ;
- une version sur fond noir ;
- une version avec damier visible ;
- une image où le damier est imprimé dans les pixels ;
- une preview ;
- une capture d’écran ;
- une image JPEG ;
- une image sans alpha ;
- une image trop grande dont le contenu sort de la zone visible sur tous les appareils ;
- une image seulement “visuellement transparente” mais non vérifiée techniquement.

Un damier affiché par un logiciel peut indiquer la transparence.
Un damier présent dans les pixels de l’image n’est pas de la transparence.

## Rôle de la bannière

La bannière @erith IA n’est pas une simple décoration.

Elle sert de panneau d’information visuel de la chaîne.

Elle doit expliquer rapidement :

- ce qui est déjà disponible ;

La bannière doit être pensée comme une frise :

`ANCIEN / DISPONIBLE → PRÉSENT / IDENTITÉ → FUTUR / À VENIR`

## Zone safe

La bannière complète est en 2048 × 1152.

Mais le contenu important doit rester dans la zone centrale visible sur tous les appareils.

Référence de travail :

- zone safe approximative : 1235 × 338 px ;
- centrée dans le canvas 2048 × 1152 ;
- tous les éléments essentiels doivent tenir dans cette zone.

Éléments essentiels :

- nom de chaîne ;
- logo ;
- personnage principal ;
- symbole ;
- message central ;
- information utile pour le spectateur.

Les éléments décoratifs peuvent s’étendre, mais ils ne doivent pas être indispensables.

## Procédure correcte

Quand Christophe demande une bannière YouTube @erith IA :

1. Identifier s’il demande une création artistique ou une correction technique.
2. Ne pas régénérer aveuglément si une image est déjà choisie.
3. Préparer un canvas 2048 × 1152.
4. Placer l’artwork au centre.
5. Réduire l’artwork si nécessaire pour qu’il tienne dans la zone safe.
6. Supprimer le fond autour.
7. Exporter en PNG RGBA.
8. Vérifier techniquement :
   - dimensions ;

   - canal alpha ;
   - poids ;
   - bbox de l’artwork ;
   - safe area.
9. Fournir le fichier final sous le nom canonique.
10. Séparer clairement les previews du fichier final.
