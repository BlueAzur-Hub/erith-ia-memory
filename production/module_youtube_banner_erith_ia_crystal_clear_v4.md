# MODULE LLM — YouTube Banner / @erith IA — Crystal Clear v4

## Statut

Module officiel de création et correction des bannières YouTube @erith IA.

Cette version remplace les anciennes versions du module.

Elle consolide :

- le format final canonique ;
- la règle de transparence réelle ;
- l’interdiction du fond blanc ;
- l’interdiction du damier ;
- la zone safe téléphone / web / TV ;
- le rôle éditorial de la bannière ;
- l’option Seven Banner Designer ;
- la référence officielle 4 seasons.

---

## Objectif

Aider à créer des bannières YouTube fiables, lisibles et techniquement propres pour la chaîne @erith.IA.

La bannière n’est pas une simple décoration.

Elle fonctionne comme un panneau d’information visuel de la chaîne.

Elle doit montrer :

- ce qui est déjà disponible ;
- l’identité actuelle de la chaîne ;
- ce qui arrive ensuite.

---

## Lecture éditoriale canonique

La bannière doit être lue comme une frise :

`ANCIEN / DISPONIBLE → PRÉSENT / IDENTITÉ → FUTUR / À VENIR`

### Gauche — Ancien / Disponible

La partie gauche représente :

- ce qui existe déjà ;
- les contenus disponibles ;
- les anciens modules ;
- les archives ;
- les fondations ;
- les premières briques jaunes ;
- les mondes déjà intégrés.

### Centre — Présent / Identité

La partie centrale est la plus importante.

Elle doit contenir :

- l’identité actuelle de la chaîne ;
- `@ERITH IA` ;
- Aerith-7 ;
- la fleur à 7 pétales ;
- le symbole principal ;
- le message lisible immédiatement.

### Droite — Futur / À venir

La partie droite représente :

- ce qui arrive ensuite ;
- les futurs modules ;
- les prochains épisodes ;
- les nouveaux mondes ;
- l’horizon narratif.

---

## Format final canonique

Le fichier final valide doit suivre ce modèle :

`ERITH_IA_BANNER_FINAL_SAFE_TRANSPARENT_RGBA_2048x1152.png`

Ce nom de fichier décrit exactement le format attendu.

Le fichier final doit être :

- PNG ;
- 2048 × 1152 px ;
- mode RGBA ;
- vrai canal alpha ;
- transparence réelle autour de l’artwork ;
- artwork centré ;
- contenu essentiel dans la zone safe visible sur tous les appareils ;
- compatible téléphone, web et TV.

---

## Règle technique absolue

Le fichier final doit être un PNG transparent réel.

Contraintes obligatoires :

- PNG ;
- 2048 × 1152 px ;
- mode RGBA ;
- vrai canal alpha ;
- alpha techniquement vérifié ;
- transparence réelle autour de l’artwork ;
- artwork centré ;
- contenu essentiel dans la zone safe ;
- aucun fond blanc ;
- aucun fond noir ;
- aucun damier ;
- aucun quadrillage ;
- aucun faux transparent.

---

## Interdictions par défaut

Fond blanc et damier sont interdits sauf demande expresse de Christophe.

Ne jamais livrer par défaut :

- un fond blanc ;
- un fond noir ;
- un damier ;
- un quadrillage ;
- un faux transparent ;
- une preview ambiguë comme fichier final ;
- une capture d’écran comme fichier final ;
- une image JPEG comme fichier final ;
- une image sans canal alpha ;
- une image qui ressemble à de la transparence sans être techniquement transparente.

---

## Règle spéciale du damier

Le damier Photoshop peut exister uniquement comme indication visuelle dans le logiciel.

Un damier imprimé dans les pixels de l’image est une erreur.

Règle d’or :

`PAS DE DAMIER DANS LE FICHIER FINAL`

---

## Règle spéciale du fond blanc

Un fond blanc peut servir uniquement de preview technique si Christophe le demande explicitement.

Par défaut :

`PAS DE FOND BLANC DANS LE FICHIER FINAL`

Le fichier final doit rester transparent autour de l’artwork.

---

## Previews

Les previews fond blanc, fond sombre ou guide safe area ne doivent être créées que si Christophe les demande explicitement.

Previews possibles sur demande :

`ERITH_IA_BANNER_PREVIEW_FOND_BLANC_2048x1152.png`

`ERITH_IA_BANNER_PREVIEW_FOND_SOMBRE_2048x1152.jpg`

`ERITH_IA_BANNER_PREVIEW_GUIDE_SAFE_AREA.jpg`

Les previews ne doivent jamais être confondues avec le fichier final.

---

## Zone safe

La bannière complète fait 2048 × 1152 px.

Le contenu essentiel doit rester dans la zone visible sur tous les appareils.

Référence de travail :

- zone safe centrale approximative : 1235 × 338 px ;
- centrée dans le canvas 2048 × 1152.

Éléments essentiels à garder dans la zone safe :

- nom de chaîne ;
- logo ;
- personnage principal ;
- symbole ;
- message central ;
- information utile pour le spectateur.

Les éléments décoratifs peuvent dépasser, mais ils ne doivent pas être indispensables à la compréhension de la bannière.

---

## Public TV / Web / Téléphone

Christophe a un public important sur télévision.

La bannière doit donc être robuste sur :

- téléphone ;
- ordinateur / web ;
- télévision.

Conséquences :

- le centre doit rester lisible ;
- l’information principale ne doit pas être collée aux bords ;
- le texte important ne doit jamais dépendre des zones latérales ;
- l’artwork doit être centré et réduit si nécessaire ;
- la bannière doit respirer.

---

## Procédure correcte

Quand Christophe demande une bannière YouTube @erith IA :

1. Comprendre s’il demande une création artistique ou une correction technique.
2. Ne pas générer de fond blanc.
3. Ne pas générer de damier.
4. Créer ou traiter l’image en 2048 × 1152.
5. Garder l’artwork centré dans la zone safe.
6. Supprimer tout fond visible.
7. Exporter en PNG RGBA.
8. Vérifier techniquement l’alpha.
9. Livrer uniquement le fichier final transparent.
10. Ne créer des previews que si Christophe les demande explicitement.

---

## Vérification obligatoire avant livraison

Avant de livrer un fichier final, vérifier :

- dimensions : 2048 × 1152 ;
- mode : RGBA ;
- canal alpha présent ;
- alpha extrema : minimum 0, maximum 255 ;
- fond réellement transparent ;
- aucun fond blanc ;
- aucun fond noir ;
- aucun damier imprimé ;
- artwork centré ;
- artwork dans la zone safe ;
- poids compatible YouTube.

---
