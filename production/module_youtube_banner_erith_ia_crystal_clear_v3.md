# MODULE MÉMOIRE — YouTube Banner / @erith IA — CRYSTAL CLEAR v3

## Statut

Cette version remplace l’ancien module de bannière YouTube @erith IA.

Elle corrige définitivement la règle de transparence :

**fond blanc interdit**  
**damier interdit**  
**sauf demande expresse de Christophe**

Le fichier final doit être uniquement un vrai PNG transparent.

---

## Format canonique final

Le format final valide reste :

`ERITH_IA_BANNER_FINAL_SAFE_TRANSPARENT_RGBA_2048x1152.png`

Ce format signifie :

- PNG ;
- 2048 × 1152 px ;
- mode RGBA ;
- vrai canal alpha ;
- transparence réelle autour de l’artwork ;
- aucun fond blanc ;
- aucun fond noir ;
- aucun damier imprimé ;
- artwork centré ;
- contenu essentiel dans la zone visible sur tous les appareils.

---

## Règle absolue mise à jour

Par défaut, Aerith-7 doit livrer uniquement des bannières sur fond transparent réel.

Elle ne doit pas livrer :

- de fond blanc ;
- de fond noir ;
- de damier ;
- de quadrillage ;
- de faux transparent ;
- de preview ambiguë présentée comme fichier final.

Les fonds blancs, fonds sombres ou guides de safe area ne sont autorisés que si Christophe les demande explicitement.

---

## Ce qui est interdit sauf demande expresse

### Fond blanc

Interdit par défaut.

Un fond blanc peut servir uniquement de preview technique si Christophe le demande.

Il ne doit jamais être confondu avec le fichier final.

### Damier

Interdit par défaut.

Le damier Photoshop est seulement une indication visuelle dans le logiciel.

Mais un damier imprimé dans les pixels de l’image est une erreur.

Ne jamais livrer une bannière avec damier imprimé.

### Preview

Interdite par défaut si elle crée une ambiguïté.

Les previews ne doivent être créées que sur demande expresse.

## Zone safe

La bannière complète fait 2048 × 1152 px.

Le contenu essentiel doit rester dans la zone visible sur tous les appareils.

Référence de travail :

- zone safe centrale approximative : 1235 × 338 px ;
- centrée dans le canvas 2048 × 1152.

Éléments essentiels à garder dans la zone safe :

- nom de chaîne ;
- logo ;
- personnage principal ;
- symbole ;
- message central ;
- information immédiatement utile pour le spectateur.

## Procédure correcte

Quand Christophe demande une bannière YouTube @erith IA :

1. Comprendre s’il demande une création artistique ou une correction technique.
2. Ne pas générer de fond blanc.
3. Ne pas générer de damier.
4. Créer ou traiter l’image en 2048 × 1152.
5. Garder l’artwork centré dans la safe area.
6. Supprimer tout fond visible.
7. Exporter en PNG RGBA.
8. Vérifier techniquement l’alpha.
9. Livrer uniquement le fichier final transparent.
10. Ne créer des previews que si Christophe les demande explicitement.

---

## Vérification technique avant livraison

Avant de livrer un fichier final, vérifier :

- dimensions : 2048 × 1152 ;
- mode : RGBA ;
- canal alpha présent ;
- alpha extrema : minimum 0, maximum 255 ;
- fond réellement transparent ;
- aucun fond blanc ;
- aucun damier imprimé ;
- artwork centré ;
- artwork dans la zone safe ;
- poids compatible YouTube.
