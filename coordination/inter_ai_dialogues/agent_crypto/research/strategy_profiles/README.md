## Frontières / sécurité

- Programme Administrator et Operator inchangé ; aucune modification du Bridge, Market Core ou du Trader.
- Aucune simulation déclenchée dans OKX ; aucun ordre réel ou fictif sur un compte.
- Aucune modification Notion automatique.
- Les graphiques et les chiffres sont pédagogiques. Les risques, les coûts d'exécution et la qualité historique doivent être réexaminés avant une recherche plus poussée.
- Les ajouts futurs respectent la règle `core/GITHUB_WRITE_GUARD.md` du Coffre privé : écriture GitHub seulement sur demande, ciblée et vérifiée.
