    ## 3. Où GitHub stocke ses données
    
    GitHub stocke dans le dépôt, ici :
    
    ```
    public/agent_crypto_erith_ia/data/
    ```
    
    Plus précisément :
    
    ```
    public/agent_crypto_erith_ia/data/latest.json
    public/agent_crypto_erith_ia/data/status.json
    public/agent_crypto_erith_ia/data/history/YYYY-MM-DD.jsonl
    ```
    
    ### `latest.json`
    
    C’est le dernier relevé GitHub.
    
    ```
    dernier snapshot
    collector_id: github-action-main
    source
    assets
    global metrics
    ```
    
    C’est ce que l’app lit actuellement quand tu charges **GitHub Memory**.
    
    ### `status.json`
    
    C’est l’état du collecteur GitHub.
    
    ```
    ok / erreur
    source utilisée
    nombre d’actifs
    dernier update
    message diagnostic
    ```
    
    ### `history/YYYY-MM-DD.jsonl`
    
    C’est l’historique journalier.
    
    Exemple :
    
    ```
    public/agent_crypto_erith_ia/data/history/2026-07-21.jsonl
    ```
    
    Chaque ligne = un snapshot GitHub.
    
    À 5 minutes :
    
    ```
    12 snapshots / heure
    288 snapshots / jour
    ```
