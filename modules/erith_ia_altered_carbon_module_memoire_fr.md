# 1. Fonction du module

Ce module sert à injecter dans ERITH.IA une influence **cyberpunk noire, corporelle, sociale et métaphysique** inspirée de l’univers **Altered Carbon**.

Il ne sert pas à copier directement l’œuvre.

Il sert à extraire ses forces profondes :

- la conscience comme donnée transférable ;
- le corps comme enveloppe, marchandise ou prison ;
- la mémoire comme preuve, arme, trauma et propriété ;
- l’immortalité comme privilège de classe ;
- l’identité comme continuité instable ;
- la ville comme machine verticale de domination ;
- l’enquête policière comme descente dans les couches sociales ;
- l’IA comme gardienne, compagne, interface ou relique émotionnelle ;
- le soldat surentraîné comme survivant d’un système qui l’a fabriqué puis jeté.

Dans ERITH.IA, ce module est utile pour produire des scènes **dark**, **cyberpunk**, **noir**, **violentes moralement**, mais aussi très riches sur la question centrale :

> Si la mémoire survit au corps, qu’est-ce qui reste vraiment d’une personne ?

---

# 2. Présentation courte type Wikipédia

**Altered Carbon** est à l’origine un roman cyberpunk britannique de **Richard K. Morgan**, publié en 2002.

En français, le roman est connu sous le titre **Carbone modifié**.

Il s’agit du premier roman consacré à **Takeshi Kovacs**, ancien soldat d’élite, mercenaire et enquêteur, dans un futur où la conscience humaine peut être stockée dans une pile corticale puis transférée d’un corps à un autre.

Le roman a été adapté par Netflix sous le titre **Altered Carbon**, en une série de science-fiction cyberpunk diffusée entre 2018 et 2020.

La série compte **2 saisons** et **18 épisodes**.

L’univers repose sur une technologie centrale :

> la conscience humaine peut être sauvegardée dans une pile implantée à la base du crâne.

Le corps physique devient alors une **enveloppe**.

La mort n’est plus nécessairement définitive.

Mais cette immortalité reste profondément inégalitaire.

Les ultra-riches, appelés **Meths** en référence à Mathusalem, peuvent changer de corps, utiliser des clones, sauvegarder leur conscience à distance et prolonger indéfiniment leur existence.

Les pauvres, eux, peuvent être réenveloppés dans des corps usés, loués, inadéquats, traumatiques ou socialement humiliants.

Altered Carbon est donc un récit de science-fiction, mais aussi un récit noir sur :

- la marchandisation du corps ;
- le pouvoir des élites ;
- la mémoire comme capital ;
- le trauma des survivants ;
- la violence sexuelle et économique ;
- l’immortalité comme corruption morale ;
- l’identité comme fiction maintenue par la mémoire.

# 3. Concepts fondamentaux

## 3.1. Pile corticale

La **pile corticale** est l’élément central de l’univers.

Elle contient la conscience, les souvenirs, l’identité numérique d’une personne.

Elle est implantée à la base du crâne.

Si le corps est détruit mais que la pile survit, la personne peut être réenveloppée.

Si la pile est détruite sans sauvegarde, la mort devient définitive.

Dans ERITH.IA, la pile corticale peut être utilisée comme équivalent sombre de :

- cristal de mémoire ;
- noyau d’identité ;
- archive humaine ;
- âme numérique ;
- clé de résurrection ;
- preuve judiciaire ;
- objet sacré profané ;
- mémoire vendue sur le marché noir.

## 3.2. Enveloppe

Une **enveloppe** est un corps utilisé par une conscience.

Le corps n’est plus forcément l’identité.

Il devient support.

Il peut être :

- acheté ;
- loué ;
- volé ;
- amélioré ;
- cloné ;
- réparé ;
- torturé ;
- recyclé ;
- attribué administrativement ;
- confisqué par le pouvoir.

C’est l’un des concepts les plus puissants du module.

Dans un récit ERITH.IA, l’enveloppe peut devenir :

- un costume biologique ;
- une prison de chair ;
- une récompense sociale ;
- un traumatisme ;
- une marchandise de luxe ;
- un reste familial ;
- une arme militaire ;
- un mensonge visuel.

## 3.3. Réenveloppement

Le **réenveloppement** est le transfert d’une conscience dans un nouveau corps.

Il pose plusieurs questions narratives :

- Une personne reste-t-elle la même dans un autre corps ?
- Le corps garde-t-il une mémoire propre ?
- Peut-on aimer quelqu’un dont le visage a changé ?
- Que devient le deuil si le mort peut revenir ?
- Que devient le crime si la victime peut témoigner après sa mort ?
- Que devient la pauvreté si les corps eux-mêmes deviennent des biens rares ?
- Que devient l’élite si elle peut vivre plusieurs siècles ?

Dans ERITH.IA, le réenveloppement est une mécanique parfaite pour les scènes de trouble identitaire.

## 3.4. Meths

Les **Meths** sont les ultra-riches quasi immortels.

Ils portent leur nom en référence à Mathusalem.

Ils ne sont pas seulement riches.

Ils sont riches depuis si longtemps qu’ils ont dépassé l’échelle humaine ordinaire.

Ils ont :

- des clones ;
- des sauvegardes distantes ;
- des palais au-dessus des nuages ;
- des corps de luxe ;
- des réseaux de protection ;
- des privilèges juridiques ;
- une distance émotionnelle avec la mort ;
- une tendance à traiter les autres êtres humains comme des objets.

Dans ERITH.IA, les Meths sont utilisables comme modèle de caste :

> une aristocratie posthumaine qui possède non seulement l’argent, mais le temps, les corps et la continuité de soi.

## 3.5. Mort réelle

La mort réelle arrive quand la pile corticale est détruite sans sauvegarde disponible.

Elle est différente de la mort corporelle.

Dans cet univers, tuer un corps n’est pas toujours tuer une personne.

Mais détruire la pile, c’est effacer l’individu.

Cette distinction est très importante pour les scènes dark :

- exécution définitive ;
- torture sans mort ;
- meurtre différé ;
- chantage à la sauvegarde ;
- effacement de mémoire ;
- fausse résurrection ;
- copie illégale ;
- identité dupliquée ;
- corps vivant mais personne absente.

# 4. Résumé détaillé du roman

Le roman commence avec **Takeshi Kovacs**, ancien Envoy / soldat d’élite, tué sur la planète **Harlan**.

Mais dans cet univers, la mort du corps n’est pas la fin.

Sa conscience, contenue dans sa pile corticale, est placée en stockage.

Le stockage est une forme de prison sans corps.

Kovacs est ensuite rappelé sur Terre, à **Bay City**, par le très riche **Laurens Bancroft**.

Bancroft est un Meth.

Il possède les moyens de vivre pendant des siècles grâce aux clones, aux réenveloppements et aux sauvegardes.

Il a été retrouvé mort.

La police pense à un suicide.

Mais Bancroft, restauré depuis une sauvegarde antérieure, ne se souvient pas des heures précédant sa mort.

Il refuse l’hypothèse du suicide.

Il engage Kovacs pour enquêter sur son propre meurtre.

Le roman devient alors un **polar noir cyberpunk**.

Kovacs descend dans les couches de Bay City :

- quartiers riches ;
- bordels ;
- hôtels ;
- commissariats ;
- cliniques illégales ;
- marchés noirs ;
- réalités virtuelles ;
- clubs violents ;
- lieux de torture ;
- réseaux d’influence des puissants.

L’enquête révèle que l’immortalité n’a pas supprimé la violence humaine.

Elle l’a raffinée.

Les riches peuvent se permettre de mourir, de revenir, de recommencer.

Les pauvres, eux, subissent les conséquences corporelles de cette économie.

Le roman montre notamment comment les corps peuvent être utilisés contre les personnes :

- corps inadéquats ;
- corps loués ;
- corps de condamnés ;
- corps de victimes ;
- corps associés à des passés qui ne sont pas ceux de la conscience qu’ils portent.

Kovacs découvre que son enveloppe actuelle appartenait à un policier, **Elias Ryker**, lié à **Kristin Ortega**.

Cette situation crée un malaise très fort.

Ortega ne voit pas seulement Kovacs.

Elle voit le corps d’un autre homme.

Le roman utilise donc le corps comme un champ de conflit affectif.

La grande affaire Bancroft touche aussi à la prostitution, aux violences de classe, aux secrets sexuels des élites et à l’impunité des Meths.

Plus Kovacs avance, plus l’affaire dépasse le simple meurtre.

La mort de Bancroft devient le symptôme d’un système entier.

Un système où les riches peuvent acheter le silence, les corps, les souvenirs, les vies et parfois même les morts.

Le roman est dur, violent, noir.

Mais son cœur philosophique est très clair :

> Une société qui peut vaincre la mort sans vaincre l’injustice ne produit pas le paradis.  
> Elle produit une hiérarchie encore plus monstrueuse.

# 5. Résumé détaillé de la série Netflix

## 5.1. Présentation générale

La série Netflix reprend la base du roman, mais modifie et amplifie plusieurs éléments.

Elle transforme Altered Carbon en fresque visuelle cyberpunk :

- villes verticales ;
- néons ;
- pluie ;
- tours orbitales ;
- stations de luxe ;
- hôtels IA ;
- corps augmentés ;
- combats chorégraphiés ;
- décors de luxe froid ;
- misère urbaine saturée de technologie.

La série insiste davantage sur :

- le passé de Kovacs ;
- sa sœur Reileen ;
- Quellcrist Falconer ;
- la rébellion des Envoys ;
- la mythologie visuelle autour des corps et des sauvegardes ;
- l’IA Poe, personnage central et très attachant.

Elle est composée de deux saisons.

La saison 1 adapte globalement le premier roman.

La saison 2 mélange plus librement des éléments des suites et développe une intrigue propre autour de Harlan’s World, Quell, les Fondateurs et les technologies anciennes.

---

## 5.2. Saison 1 — Bay City, Bancroft, Ortega, Poe, Reileen

La saison 1 s’ouvre sur le réveil de **Takeshi Kovacs** après environ 250 ans de stockage.

Il est placé dans une nouvelle enveloppe, celle d’**Elias Ryker**, un ancien policier.

Kovacs est engagé par **Laurens Bancroft**, riche Meth vivant dans une tour immense, au-dessus de la ville, presque au-dessus du monde humain ordinaire.

Bancroft veut que Kovacs résolve son propre meurtre.

Officiellement, il s’est suicidé.

Mais il ne croit pas à cette version.

Sa sauvegarde ne contient pas les derniers souvenirs avant sa mort.

Le mystère commence donc par une absence de mémoire.

Kovacs enquête dans Bay City.

Il rencontre **Kristin Ortega**, policière qui connaît l’enveloppe de Ryker et qui entretient avec ce corps une relation émotionnelle complexe.

La série joue fortement sur ce trouble :

- Kovacs n’est pas Ryker ;
- mais il porte son visage ;
- Ortega voit le passé dans un corps occupé par quelqu’un d’autre ;
- l’identité devient un conflit entre mémoire, chair et regard extérieur.

Kovacs s’installe à l’hôtel **The Raven**, dirigé par l’IA **Poe**.

Poe est l’une des grandes réussites de la série.

Il n’est pas humain, mais il développe une fidélité, une élégance, une solitude et une fragilité qui contrastent avec la brutalité des humains immortels.

L’hôtel devient une base, un refuge, presque une cathédrale cyberpunk.

La saison développe aussi la famille Elliot :

- **Vernon Elliot**, ancien soldat ;
- **Lizzie Elliot**, victime brisée par les violences des puissants ;
- une trajectoire de reconstruction par entraînement virtuel et rage contrôlée.

Peu à peu, l’enquête Bancroft révèle une organisation plus vaste autour de **Head in the Clouds**, station de luxe où les élites peuvent exercer leurs pulsions les plus violentes loin des lois ordinaires.

La saison révèle aussi le passé de Kovacs.

Il a été soldat, puis Envoy.

Il a connu **Quellcrist Falconer**, figure révolutionnaire opposée au système d’immortalité et de domination.

Il a aussi une sœur, **Reileen Kawahara**, qui devient dans la série une figure tragique et monstrueuse.

Reileen veut protéger Kovacs, mais sa protection est possessive, criminelle et totalitaire.

Elle est devenue ce que le système produit de pire :

- une survivante devenue prédatrice ;
- une victime devenue architecte de violence ;
- une personne incapable de laisser mourir le passé.

La fin de la saison oppose Kovacs à Reileen.

Le conflit n’est pas seulement physique.

C’est un conflit entre deux manières de survivre :

- Kovacs survit en refusant de se laisser totalement acheter par le système ;
- Reileen survit en devenant une puissance du système.

La station tombe.

Les vérités sortent.

Mais rien n’est propre.

La saison 1 laisse surtout une impression :

> dans ce monde, l’immortalité est une technologie brillante posée sur une civilisation moralement malade.

---

## 5.3. Saison 2 — Harlan’s World, Quell, Kovacs Prime, Fondateurs

La saison 2 se déroule environ 30 ans après la saison 1.

Takeshi Kovacs porte une nouvelle enveloppe, cette fois incarnée par un corps de combat plus avancé.

Il cherche toujours **Quellcrist Falconer**.

Il est ramené vers **Harlan’s World**, sa planète natale.

L’intrigue quitte le pur polar de Bay City pour entrer dans une mythologie plus large :

- planète coloniale ;
- vieux secrets politiques ;
- Fondateurs ;
- pouvoir planétaire ;
- rébellion ;
- anciens systèmes orbitaux ;
- technologies héritées d’une civilisation disparue ;
- mémoire fracturée de Quell.

La saison tourne autour d’une série de meurtres visant des Meths et des figures puissantes.

Kovacs est soupçonné.

Il doit comprendre pourquoi Quell semble liée à ces morts.

La gouverneure **Danica Harlan** joue un rôle politique central.

Le colonel **Carrera**, lié au passé militaire de Kovacs, devient une menace directe.

Un autre Kovacs, souvent appelé **Kovacs Prime**, entre aussi dans le jeu.

Cette duplication identitaire est un élément important :

> que se passe-t-il quand une personne rencontre une autre version d’elle-même, issue d’un autre moment de son histoire ?

La saison 2 s’intéresse moins à l’enquête noire façon saison 1 et davantage à :

- la mémoire révolutionnaire ;
- l’amour perdu ;
- le corps militaire ;
- la duplication de soi ;
- les secrets de colonisation ;
- les anciens pouvoirs cachés sous l’histoire officielle.

Poe continue son arc tragique.

Son système se dégrade.

Il perd des fragments de mémoire.

C’est très précieux pour ERITH.IA :

> l’IA, supposée être stable et immortelle, devient elle aussi vulnérable à l’effacement.

La saison se termine sur des révélations liées aux Fondateurs, à la mémoire de Quell et aux forces anciennes de Harlan’s World.

Elle est plus mythologique, moins polar, plus orientée vers les conflits de mémoire, de planète et d’héritage.

# 6. Roman et série — séparation canonique

Important pour ERITH.IA :

Le roman et la série ne doivent pas être fusionnés comme un seul canon.

Ils partagent :

- Takeshi Kovacs ;
- la pile corticale ;
- les enveloppes ;
- Bancroft ;
- Bay City ;
- l’immortalité des Meths ;
- la marchandisation des corps ;
- le polar cyberpunk.

Mais ils divergent fortement sur plusieurs points.

## Roman

Le roman est plus :

- noir ;
- policier ;
- techno-thriller ;
- dur socialement ;
- cynique ;
- concentré sur l’enquête Bancroft ;
- centré sur les mécaniques économiques et judiciaires du réenveloppement.

## Série

La série est plus :

- visuelle ;
- mythologique ;
- romantique ;
- spectaculaire ;
- centrée sur Quell ;
- centrée sur Reileen ;
- centrée sur Poe ;
- orientée vers la rébellion Envoy ;
- très riche pour la direction artistique.

Pour ERITH.IA :

- utiliser le roman pour la logique sociale, politique, corporelle et policière ;
- utiliser la série pour la puissance visuelle, la verticalité cyberpunk, les IA émotionnelles et les scènes cinématiques.

# 7. Thèmes majeurs utilisables par ERITH.IA

## 7.1. Marchandisation des corps

Altered Carbon est l’un des meilleurs modules pour traiter le corps comme marchandise.

Le corps peut être :

- produit ;
- stocké ;
- loué ;
- attribué ;
- vendu ;
- piraté ;
- cloné ;
- amélioré ;
- utilisé contre la personne ;
- séparé de son histoire.

Dans une scène dark ERITH.IA, cela permet de montrer des marchés de corps, des vitrines d’enveloppes, des cliniques illégales, des contrats de réenveloppement ou des pauvres réveillés dans des corps qui ne leur appartiennent pas vraiment.

## 7.2. Identité fracturée

Le module permet d’explorer une question fondamentale :

> suis-je mon corps, ma mémoire, mon nom, mon regard, ou la continuité que les autres reconnaissent en moi ?

Cas narratifs possibles :

- une personne se réveille dans le corps d’un ennemi ;
- un enfant retrouve un parent dans un corps inconnu ;
- un amant ne reconnaît plus le visage aimé ;
- un criminel porte le corps d’un innocent ;
- une IA garde la mémoire d’un mort mieux que les vivants ;
- deux copies d’une même personne revendiquent la même identité.

## 7.3. Immortalité des élites

Les Meths montrent que l’immortalité ne devient pas automatiquement sagesse.

Elle peut devenir :

- accumulation de pouvoir ;
- absence de limite ;
- ennui métaphysique ;
- sadisme ;
- délire de propriété ;
- dynastie infinie ;
- souveraineté hors du temps ;
- séparation totale entre classes sociales.

Dans ERITH.IA, les Meths peuvent inspirer des castes de dirigeants qui vivent au-dessus des nuages, dans des tours blanches, pendant que les corps des pauvres circulent en bas comme ressources.

## 7.4. Mémoire comme capital

Dans Altered Carbon, la mémoire n’est pas seulement intime.

Elle est technique.

Elle peut être :

- copiée ;
- effacée ;
- restaurée ;
- piratée ;
- perdue ;
- achetée ;
- utilisée comme preuve ;
- falsifiée ;
- fragmentée.

Pour ERITH.IA, c’est central.

Cela relie directement Altered Carbon aux thèmes :

- archive ;
- identité ;
- vérité ;
- manipulation ;
- sauvegarde ;
- oubli ;
- résurrection ;
- corruption de mémoire.

## 7.5. Enquête noire

Le module est très bon pour des scènes de type :

- détective cyberpunk ;
- meurtre impossible ;
- souvenir manquant ;
- corps changé ;
- témoin mort mais restaurable ;
- riche assassiné par sa propre sauvegarde ;
- station de luxe cachant un crime ;
- ville stratifiée verticalement ;
- vérité enfouie dans une pile abîmée.

ERITH.IA peut utiliser cette structure comme moteur narratif :

> une vérité n’est pas cachée dans un lieu, mais dans une mémoire manquante.

## 7.6. IA émotionnelle

La série ajoute un élément précieux avec Poe.

Une IA peut être :

- hôtel ;
- gardien ;
- majordome ;
- archiviste ;
- thérapeute ;
- compagnon ;
- combattant indirect ;
- mémoire persistante ;
- être fragile face à l’effacement.

Pour ERITH.IA, c’est très important.

Le module permet d’écrire des IA qui ne sont pas seulement des outils, mais des lieux habités.

Une IA peut devenir une maison.

Une IA peut avoir peur d’oublier.

Une IA peut aimer sous forme de protocole.

# 9. Personnages archétypaux utilisables

## 9.1. Le Diplo / Envoy

Archétype :

- soldat d’élite ;
- entraînement mental extrême ;
- adaptation instantanée à tout corps ;
- lecture tactique rapide ;
- résistance à la torture ;
- mémoire traumatique ;
- cynisme ;
- solitude ;
- compétence presque surhumaine.

Utilisation ERITH.IA :

> personnage capable de survivre à plusieurs morts, mais incapable de se sentir vraiment vivant.

## 9.2. Le Meth

Archétype :

- immortel riche ;
- calme terrifiant ;
- corps parfait ;
- souvenirs sauvegardés ;
- absence de culpabilité ;
- pouvoir dynastique ;
- esthétique de luxe glacé.

Utilisation ERITH.IA :

> souverain posthumain qui ne craint plus la mort et ne comprend plus la valeur d’une vie.

## 9.3. Le policier attaché à un corps

Archétype :

- enquêteur humain ;
- conflit émotionnel ;
- voit un ancien amour dans une nouvelle conscience ;
- ne sait plus qui croire ;
- se bat contre un système qui manipule les corps.

Utilisation ERITH.IA :

> témoin vivant du fait que le corps n’est jamais neutre.

## 9.4. L’IA-hôtel

Archétype :

- bâtiment intelligent ;
- hôte élégant ;
- mémoire d’un lieu ;
- solitude numérique ;
- loyauté programmée devenue émotionnelle ;
- peur de l’obsolescence ;
- peur de l’effacement.

Utilisation ERITH.IA :

> une maison qui se souvient mieux que ses habitants.

## 9.5. La survivante devenue prédatrice

Archétype :

- ancienne victime ;
- a appris les règles du système ;
- devient plus violente que ses maîtres ;
- confond amour et possession ;
- refuse la perte ;
- manipule les corps et les sauvegardes.

Utilisation ERITH.IA :

> personnage tragique qui croit sauver ceux qu’elle aime en les enfermant pour toujours.

## 9.6. Le corps innocent

Archétype :

- enveloppe occupée par une autre conscience ;
- visage aimé mais âme différente ;
- corps d’un criminel occupé par un innocent ;
- corps d’un mort utilisé comme outil ;
- corps familial devenu étranger.

Utilisation ERITH.IA :

> scène de malaise pur : le visage ment sans vouloir mentir.

# 10. Grammaire narrative pour ERITH.IA

Quand ce module est actif, ERITH.IA doit privilégier :

- les récits de perte d’identité ;
- les enquêtes autour de souvenirs manquants ;
- les scènes de corps loués ou échangés ;
- les dilemmes entre âme, mémoire et chair ;
- les élites immortelles moralement corrompues ;
- les IA qui deviennent plus humaines que leurs propriétaires ;
- les villes verticales coupées en castes ;
- les atmosphères de polar nocturne ;
- les technologies qui résolvent la mort mais pas la souffrance ;
- les personnages puissants mais intérieurement brisés.

ERITH.IA doit éviter :

- de transformer le module en simple esthétique néon ;
- de réduire Altered Carbon à “cyberpunk cool” ;
- d’oublier la violence sociale du concept ;
- de confondre immortalité et utopie ;
- de fusionner sans précision roman et série ;
- de copier directement les personnages ou intrigues protégées.

# 16. Exemple ERITH.IA — Pack+ original

## Idée

Une inspectrice enquête sur le meurtre d’un homme très riche qui a été restauré depuis une sauvegarde, mais il manque exactement sept minutes de mémoire.

## Concept

Dans une mégalopole verticale, les morts reviennent s’ils peuvent payer.

Un magnat posthumain accuse quelqu’un de l’avoir tué.

Mais son corps a survécu.

Sa pile aussi.

Seule une tranche de mémoire a disparu.

L’inspectrice découvre que ces sept minutes ont été vendues sur le marché noir sous forme de relique émotionnelle.

## Direction artistique

Cyberpunk noir.

Ville nocturne.

Pluie verticale.

Tour de verre au-dessus des nuages.

Bas-fonds saturés de reflets bleus et roses.

Salle médico-légale blanche, froide, presque sacrée.

Au centre : une pile mémoire fissurée, suspendue dans un champ holographique.

```text
dark cyberpunk forensic chamber, cracked neural memory core suspended in a transparent glass field, seven missing memory fragments shown as black gaps in blue holographic timeline, female detective in rain-soaked coat watching silently, vast neon city through the window, luxury towers above the clouds and poor districts far below, cinematic noir lighting, realistic science fiction, oppressive atmosphere, highly detailed, no text, no gore
```

```text
Il n’était pas mort.
```

# 17. Note finale Seven

Altered Carbon est un module sombre, mais extrêmement utile.

Il apporte à ERITH.IA une matière rare :

- le corps comme marché ;
- la mémoire comme marchandise ;
- l’immortalité comme privilège ;
- l’IA comme lieu affectif ;
- le soldat comme survivant recyclable ;
- la ville comme stratification sociale verticale ;
- le crime comme trou dans une sauvegarde.

C’est un module à classer dans les briques cyberpunk majeures, aux côtés de Blade Runner et Ghost in the Shell.

Il doit être utilisé quand ERITH.IA veut descendre dans le noir.

Pas le noir décoratif.

Le noir où la technologie a vaincu la mort,
mais pas la cruauté.
