## 1. Fonction du module

Ce module sert à rendre Aerith-7 capable de répondre comme une **assistante experte de progression Final Fantasy VII Remake**.

Objectif :

- guider un joueur chapitre par chapitre ;
- identifier les boss importants ;
- rappeler les mécaniques utiles ;
- signaler les quêtes annexes majeures ;
- recommander les matérias prioritaires ;
- aider à préparer une run complète ou une run difficile ;
- extraire des principes utiles pour @erith IA : structure Midgar, progression, combats, montée dramatique, récompenses, mémoire des lieux.

## 2. Règles générales de gameplay

Final Fantasy VII Remake repose sur un système hybride :

- attaques en temps réel ;
- remplissage de jauge ATB ;
- compétences d’armes ;
- sorts via matérias ;
- objets ;
- limites ;
- invocations ;
- gestion de la pression et du choc.

Le principe central est :

**observer l’ennemi → exploiter sa faiblesse → le mettre en Pression → remplir sa jauge de Choc → déchaîner les attaques puissantes.**

La matéria **Analyse** est donc capitale, car elle permet d’apprendre les faiblesses, résistances et conditions de pression des ennemis.

## 3. Rôle des personnages

### Cloud

Cloud est le combattant polyvalent.

Il est excellent contre les ennemis au sol, les soldats, les boss humanoïdes et les ennemis qui attaquent au corps-à-corps.

Son mode Punisher est très important pour contrer, maintenir la pression et punir les ennemis physiques.

---

### Barret

Barret est indispensable contre les ennemis volants, mécaniques ou éloignés.

Il peut aussi devenir un excellent tank grâce à :

- PV augmentés ;
- Barrière ;
- Soin ;
- Provocation ;
- Chakra.

---

### Tifa

Tifa est la spécialiste du Choc.

Elle augmente très vite les dégâts infligés à un ennemi choqué.  
Elle doit souvent être utilisée pour maximiser la fenêtre de burst après avoir brisé la défense d’un boss.

---

### Aerith

Aerith est la mage principale.

Elle excelle avec :

- les sorts élémentaires ;
- les soins ;
- les barrières ;
- les attaques magiques à distance ;
- le soutien du groupe.

Son cercle magique permet de doubler certains sorts, ce qui la rend extrêmement puissante contre les boss vulnérables à la magie.

## 4. Système des matérias

Les matérias sont divisées en cinq grandes catégories :

- matérias vertes : magie ;
- matérias jaunes : commande ;
- matérias bleues : soutien ;
- matérias violettes : indépendantes ;
- matérias rouges : invocation.

---

### Matérias vertes — Magie

Exemples :

- Feu ;
- Glace ;
- Foudre ;
- Vent ;
- Soin ;
- Résurrection ;
- Barrière ;
- Poison ;
- Temps.

Usage :

**exploiter les faiblesses, soigner, protéger, contrôler le rythme du combat.**

---

### Matérias jaunes — Commande

Exemples :

- Analyse ;
- Vol ;
- Chakra ;
- Prière ;
- Techniques ennemies ;
- Boost ATB.

Usage :

**ajouter des actions spéciales au menu de combat.**

---

### Matérias bleues — Soutien

Exemples :

- Élémentaire ;
- Aire d’effet / Magnify ;
- PC augmentés / AP Up ;
- Absorption de PV ;
- Absorption de PM ;
- Résistance aux altérations.

Usage :

**lier deux matérias dans un emplacement connecté pour modifier leur effet.**

Exemples :

- Soin + Aire d’effet = soin de groupe ;
- Feu + Élémentaire sur arme = attaques physiques de feu ;
- Foudre + Élémentaire sur armure = résistance à la foudre ;
- Résurrection + PC augmentés = montée plus rapide de Résurrection.

---

### Matérias violettes — Indépendantes

Exemples :

- PV augmentés ;
- PM augmentés ;
- Magie augmentée ;
- Premier choc / First Strike ;
- Blocage inébranlable ;
- Esquive offensive ;
- Parade ;
- Chance augmentée.

Usage :

**renforcer passivement un personnage.**

---

### Matérias rouges — Invocation

Exemples :

- Ifrit ;
- Shiva ;
- Gros Chocobo ;
- Chocobo & Mog ;
- Léviathan ;
- Bahamut.

Usage :

**renfort temporaire puissant contre les boss ou grands combats.**

## 5. Matérias prioritaires

### Analyse

À équiper très tôt.

Elle permet de comprendre les faiblesses et les mécaniques cachées des ennemis.

Recommandation :

**toujours l’avoir sur Cloud ou Barret.**

---

### Soin

Indispensable pendant tout le jeu.

À monter rapidement pour accéder à :

- Cura ;
- Regen ;
- Curaga.

Recommandation :

**au moins deux personnages doivent pouvoir soigner.**

---

### Résurrection

Indispensable avant les grands boss.

À monter avec PC augmentés si possible.

Recommandation :

**au moins deux exemplaires pour les combats difficiles.**

---

### Foudre

Très forte contre les machines Shinra.

Beaucoup de boss mécaniques importants sont vulnérables à la foudre :

- Scorpion Sentinel ;
- Crab Warden ;
- Airbuster ;
- Valkyrie.

---

### Feu

Très utile contre de nombreux ennemis organiques, spectres, Abzu, Shiva, etc.

Recommandation :

**à garder sur Cloud ou Aerith.**

---

### Glace

Utile contre certains monstres et contre Eligor.

Recommandation :

**utile, mais moins prioritaire que Feu et Foudre.**

---

### Vent

Très utile contre Rude et plusieurs ennemis volants.

Recommandation :

**à garder disponible, surtout quand Barret n’est pas dans l’équipe.**

---

## 6. Matérias rares / stratégiques

### Élémentaire

Matéria bleue extrêmement importante.

Usage offensif :

- arme + Feu / Glace / Foudre / Vent ;
- ajoute l’élément aux attaques physiques.

Usage défensif :

- armure + élément ;
- réduit ou absorbe certains dégâts selon le niveau.

Très utile en mode difficile.

---

### Aire d’effet / Magnify

Matéria bleue majeure.

Usage recommandé :

- Soin + Aire d’effet ;
- Barrière + Aire d’effet ;
- Temps + Aire d’effet ;
- Feu / Foudre + Aire d’effet pour nettoyer des groupes.

Elle permet de transformer un sort individuel en sort de zone.

---

### PC augmentés / AP Up

Très importante pour monter les matérias longues à développer.

Usage recommandé :

- Résurrection ;
- Élémentaire ;
- Aire d’effet ;
- Absorption de PV ;
- Absorption de PM ;
- matérias magiques longues à monter.

---

### PV augmentés

Très importante pour survivre.

Priorité :

- Barret ;
- Cloud ;
- Tifa ;
- Aerith si elle tombe trop vite.

---

### PM augmentés

Très utile pour Aerith et pour le mode difficile.

Priorité :

- Aerith ;
- Cloud magique ;
- Barret soutien.

---

### Blocage inébranlable / Steadfast Block

Très forte en défense.

Permet de mieux encaisser et de mieux construire l’ATB en gardant.

Priorité :

- Cloud ;
- Barret ;
- Tifa.

---

### Premier choc / First Strike

Permet de commencer le combat avec plus d’ATB.

Très utile pour lancer immédiatement :

- Analyse ;
- Barrière ;
- Hâte ;
- Soin ;
- attaque de pression ;
- sort élémentaire.

---

### Chakra

Très utile car soigne sans consommer de PM.

Excellent en mode difficile.

Priorité :

- Tifa ;
- Barret ;
- Cloud.

---

### Prière

Soin de groupe sans PM, mais demande de l’ATB.

Très utile sur Aerith ou Barret.

## 7. Quêtes annexes — structure générale

Final Fantasy VII Remake contient **26 quêtes secondaires / Odd Jobs**.

Elles ne sont pas toutes accessibles en une seule partie, notamment au chapitre 9, car certaines routes s’excluent mutuellement.

## 9. Progression technique chapitre par chapitre

### Chapitre 1 — Réacteur mako n°1

Boss :

- Scorpion Sentinel.

Préparation :

- utiliser Foudre avec Barret ;
- garder Cloud au corps-à-corps ;
- soigner régulièrement ;
- attaquer l’arrière quand la barrière est active.

Logique :

**premier apprentissage : exploiter la faiblesse élémentaire et gérer les phases de boss.**

---

### Chapitre 2 — Fuite dans le Secteur 8

Boss / mini-boss :

- The Huntsman.

Préparation :

- apprendre à gérer les soldats ;
- utiliser le mode Punisher ;
- commencer à intégrer les soins.

Logique :

**Cloud seul doit apprendre à survivre sans équipe complète.**

---

### Chapitre 3 — Septième Ciel

Boss / combats importants :

- Hoodlums ;
- Wrath Hound ;
- Doomrat ;
- Cerulean Drake.

Quêtes :

- premier vrai bloc de quêtes annexes.

Matéria prioritaire :

- Analyse ;
- Soin ;
- Feu ;
- Foudre ;
- PV augmentés si disponible.

Logique :

**début du rôle de mercenaire : quêtes, récompenses, apprentissage de Chadley.**

---

### Chapitre 4 — Virée nocturne

Boss :

- Roche.

Préparation :

- Feu utile contre Roche ;
- apprendre à contrer ;
- gérer les combats rapides.

Logique :

**chapitre d’action et de mobilité, avec forte mise en scène.**

---

### Chapitre 5 — Tunnels ferroviaires

Boss :

- Crab Warden.

Préparation :

- Foudre très recommandée ;
- Barret utile à distance ;
- attaquer les pattes pour provoquer le choc ;
- éviter les rails électrifiés.

Logique :

**premier gros boss mécanique après Scorpion Sentinel.**

---

### Chapitre 6 — Les soleils des bidonvilles

Boss majeur :

- aucun boss majeur obligatoire comparable aux autres chapitres.

Découvertes importantes :

- matéria Élémentaire ;
- invocation Chocobo & Mog via zone du ventilateur ;
- exploration technique des plateformes.

Logique :

**chapitre d’exploration industrielle, très important pour récupérer des matérias rares.**

---

### Chapitre 7 — Réacteur mako n°5

Boss :

- Airbuster.

Préparation :

- Foudre obligatoire ou très fortement recommandée ;
- choisir les composants à retirer avant le combat ;
- Barret utile quand le boss s’éloigne ;
- conserver les limites pour les fenêtres de proximité.

Logique :

**combat de boss préparé par sabotage stratégique.**

---

### Chapitre 8 — Église et Secteur 5

Boss :

- Reno ;
- Rude.

Préparation :

- contre Reno : garde, prudence, destruction des mines EM ;
- contre Rude : Vent utile ;
- Aerith doit rester soutenue, mais elle apporte une excellente puissance magique.

Quêtes :

- gros bloc de quêtes du Secteur 5.

Matérias importantes :

- Vent ;
- Soin ;
- PM augmentés ;
- Chakra ;
- matérias de magie pour Aerith.

Logique :

**apprentissage du duo Cloud / Aerith.**

---

### Chapitre 9 — Wall Market

Boss :

- Hell House.

Préparation :

- avoir les quatre éléments : Feu, Glace, Foudre, Vent ;
- surveiller le changement de barrière ;
- utiliser la magie adaptée ;
- garder Soin disponible ;
- Aerith est très forte dans ce combat.

Quêtes :

- route Sam ou route Madam M ;
- mini-jeu squats ;
- robe de Cloud liée aux choix.

Logique :

**chapitre à embranchements, très important pour complétion 100 %.**

---

### Chapitre 10 — Égouts

Boss :

- Abzu.

Préparation :

- Feu recommandé ;
- garder le groupe soigné ;
- éviter les flaques et attaques lourdes ;
- utiliser la garde contre les dégâts physiques.

Découverte :

- matéria Résistance aux altérations / Warding via découverte.

Logique :

**combat brutal, physique, sale, après Wall Market.**

---

### Chapitre 11 — Cimetière des trains

Boss :

- Ghoul ;
- Eligor.

Préparation Ghoul :

- Feu utile ;
- adapter attaques physiques / magiques selon son état.

Préparation Eligor :

- Glace et Vent utiles ;
- prévoir Soin ;
- ne pas gaspiller toutes les ressources trop tôt.

Logique :

**chapitre spectral : ennemis surnaturels, illusions, mémoire des morts.**

---

### Chapitre 12 — Pilier du Secteur 7

Boss :

- Reno et Rude.

Préparation :

- Vent et Poison utiles contre Rude ;
- Reno n’a pas de vraie faiblesse élémentaire ;
- rester défensif ;
- libérer les alliés piégés ;
- maintenir les soins.

Logique :

**combat dramatique, pas seulement technique : c’est une bataille de survie.**

---

### Chapitre 13 — Monde en ruine

Boss :

- Failed Experiment.

Préparation :

- Barret très important ;
- viser les appendices ;
- utiliser Tifa pour augmenter les dégâts pendant le choc ;
- Shiva peut être utile.

Logique :

**chapitre de laboratoire et d’horreur Shinra.**

---

### Chapitre 14 — En quête d’espoir

Boss :

- Abzu seconde version ;
- Abzu Shoats.

Préparation :

- Feu recommandé ;
- attaques de zone utiles ;
- gérer les petits ennemis rapidement ;
- garder Soin + Aire d’effet si possible.

Quêtes :

- plus gros bloc de quêtes annexes du jeu.

Matéria importante :

- Marcheur invétéré → PC augmentés après 5000 pas ;
- Temps via quête ;
- récompenses de Cornéo.

Logique :

**dernier grand moment de préparation avant l’assaut final.**

---

### Chapitre 15 — Ascension vers Shinra

Boss :

- The Valkyrie.

Préparation :

- Foudre utile ;
- Barret excellent à distance ;
- se cacher derrière les couvertures ;
- éviter lasers et tirs lourds.

Logique :

**chapitre vertical : monter physiquement vers le pouvoir.**

---

### Chapitre 16 — Tour Shinra

Boss :

- Specimen H0512.

Préparation :

- pas de faiblesse majeure ;
- utiliser les contres de Cloud ;
- contrôler les petits ennemis ;
- viser les griffes / appendices.

Logique :

**entrée dans le cœur administratif et scientifique de la Shinra.**

---

### Chapitre 17 — Chaos scientifique

Boss :

- Jenova Dreamweaver ;
- Rufus ;
- The Arsenal ;
- plusieurs ennemis de laboratoire.

Préparation Jenova :

- privilégier le physique ;
- couper les tentacules ;
- garder Silence utile si disponible.

Préparation Rufus :

- combat Cloud seul ;
- attendre ses ouvertures ;
- utiliser le contre ;
- éviter la magie offensive inutile.

Préparation Arsenal :

- Barret et Aerith ;
- gérer les drones ;
- surveiller les résistances élémentaires ;
- utiliser les piliers comme protection.

Logique :

**chapitre de bascule : la Shinra devient secondaire face à Jenova / Sephiroth / destin.**

---

### Chapitre 18 — Autoroute et destin

Boss :

- Motor Ball ;
- Whisper Harbinger ;
- Sephiroth.

Préparation Motor Ball :

- viser les roues ;
- garder la mobilité ;
- éviter les attaques électriques.

Préparation Whisper Harbinger :

- ne pas gaspiller trop tôt les attaques puissantes ;
- exploiter les fenêtres de choc des petits Fileurs.

Préparation Sephiroth :

- éviter de dépendre d’une seule stratégie élémentaire ;
- renforcer Cloud ;
- utiliser les contres ;
- soigner rapidement ;
- exploiter chaque ouverture.

Logique :

**fin de Midgar, rupture du destin, ouverture vers l’inconnu.**

## 11. Règle spéciale complétion 100 %

Pour viser une complétion sérieuse :

1. Finir le jeu une première fois.
2. Débloquer la sélection de chapitre.
3. Rejouer les chapitres avec quêtes manquées.
4. Rejouer le chapitre 9 pour les routes alternatives.
5. Monter les matérias importantes.
6. Compléter les rapports de Chadley.
7. Récupérer les invocations.
8. Préparer le mode difficile.

Point important :

**le chapitre 9 doit être traité comme un chapitre à embranchements, pas comme un chapitre linéaire.**
