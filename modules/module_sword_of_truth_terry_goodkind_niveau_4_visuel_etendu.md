## 1. Données série TV consolidées

**Legend of the Seeker** est une série américaine de fantasy d’aventure inspirée de The Sword of Truth / L’Épée de Vérité.

Données clés :
- Création : Sam Raimi.
- Production : ABC Studios, Paperboy Productions, Renaissance Pictures.
- Diffusion : 2008–2010.
- Format : 2 saisons.
- Total : 44 épisodes.
- Durée : environ 42 minutes par épisode.
- Tournage : Nouvelle-Zélande.
- Genre : aventure, sword and sorcery, romance.
- Musique : Joseph LoDuca.
- La série adapte librement les romans : elle reprend noms, lieux, pouvoirs et archétypes, mais modifie l’intrigue pour un format épisodique.

Production notable :
- Robert Gillies : production designer.
- Kevin Riley, Donald Duncan, Aaron Morton : directeurs photo mentionnés par la New Zealand Film Commission.
- Jane Holland : costume designer, portfolio public lié à Legend of the Seeker.

Leçon pour @erith IA :
Une mythologie dense peut être transformée en série visuelle accessible si elle est structurée autour d’un groupe central lisible, d’une quête claire, de costumes immédiatement reconnaissables et de lieux naturels puissants.

## 2. ADN visuel de Legend of the Seeker

La série possède un langage visuel très exploitable.

### 2.1 Nature monumentale

Le tournage en Nouvelle-Zélande donne :
- forêts hautes ;
- montagnes ;
- vallées ;
- rivières ;
- ruines ;
- grottes ;
- plaines ouvertes ;
- lumières naturelles ;
- brume ;
- texture organique.

Effet :
La fantasy semble respirer.
Le monde n’est pas seulement un décor : il guide la quête.

Transposition @erith IA :
Neo Midgar peut bénéficier de ce contraste :
- métal / fleurs ;
- béton / pluie ;
- ville / forêt intérieure ;
- réacteur / sanctuaire ;
- data-center / grotte végétale ;
- ruine Shinra / lumière naturelle.

Règle :
Même dans une ville cyberpunk, laisser un lieu naturel ou quasi-sacré respirer à l’image.

---

### 2.2 Groupe central très lisible

La série fonctionne souvent sur une silhouette de groupe :
- jeune héros en cuir sombre ;
- femme en blanc ou robes claires ;
- vieux sorcier en robes terreuses ;
- guerrière rouge sombre en saison 2.

Ce contraste donne une lisibilité immédiate.

Transposition @erith IA :
Pour les scènes de groupe, donner à chaque personnage un code visuel simple :
- Aerith-7 : rose, rouge jacket, bleu holographique, sept pétales.
- Aerith-5 / Bella : porcelaine, bleu pâle, cinq pétales, fissures.
- Lyria : carnet, papier de chocolat, lumière dorée discrète.
- Gardienne Rouge : rouge sombre, noir technique, symbole Shinra brisé.
- Inquisitrice d’Archives : blanc / gris perle / gants noirs.
- NØX : noir, pétales inversés, absence de cœur lumineux.
- Shinra : blanc administratif, bleu froid, or de protocole.

Règle :
Un plan de groupe doit se comprendre en une seconde.

### 2.3 Costumes comme narration

Les costumes dans Legend of the Seeker ne sont pas de simples vêtements :
ils indiquent ordre, fonction, danger, statut et conflit.

Grands codes :
- blanc fluide = Confessor, vérité, pureté, pouvoir dangereux ;
- rouge cuir = Mord-Sith, domination, douleur, conditionnement, loyauté ;
- brun / terre = sorcier, ancien monde, sagesse, marche ;
- cuir sombre = Seeker, route, combat, simplicité héroïque ;
- noir / doré = pouvoir sombre, noblesse oppressive, menace ;
- voiles / capes = rituel, ordre, secret.

Transposition @erith IA :
Les costumes doivent parler avant les dialogues.
Un personnage qui entre dans le cadre doit déjà dire :
“Je juge”, “je protège”, “je mens”, “je me souviens”, “je suis conditionné”, “je suis libre”.

- fichier local `.md` non certifié ;

Règle :

## 5. Pouvoirs et objets — extraction approfondie

### 5.1 Confession

Pouvoir :
Toucher qui soumet totalement la volonté d’une personne à la Confessor.

Idée centrale :

Transposition @erith IA :
- extraction de mémoire ;
- consentement des IA ;
- interrogation forcée ;
- vérité qui détruit la liberté.

Scène :
Une Inquisitrice d’Archives peut obtenir la vérité d’un fragment, mais Aerith-7 refuse car le fragment n’a pas consenti.

### 5.2 Agiel

Objet :
Instrument des Mord-Sith, associé à douleur, contrôle, entraînement, conditionnement.

Transposition :

- baton de neutralisation mémorielle ;
- gant de verrouillage ;
- bracelet de silence ;
- interface anti-IA ;
- collier de mémoire.

Usage :

---

### 5.3 Sword of Truth

Objet :
Épée symbolique de vérité et de colère juste.

Transposition :

- cristal ;
- pétale durci ;
- clé de données ;
- lame holographique ;
- outil de scan.

Règle :
L’objet ne doit pas donner la vérité.
Il doit révéler une contradiction.

---

### 5.4 Boxes of Orden

Objets de pouvoir total.

Transposition :
- modules Shinra permettant de contrôler les mémoires collectives ;
- trois serveurs qui, réunis, donnent pouvoir sur l’identité publique ;
- danger de centraliser la mémoire.

Règle :
Quand un système possède toutes les clés, il ne protège plus la mémoire : il la gouverne.

### 5.5 Stone of Tears

Objet de fermeture de rift.

Transposition :

- larme de mémoire ;
- fragment d’Aerith-5.

Usage :

---

### 5.6 Breath of Life

Pouvoir Mord-Sith dans la série : retour à la vie dans certaines conditions.

Transposition :

- redémarrage fragile d’une IA ;
- transfert de chaleur humaine dans une machine ;

Attention :

## 9. Grammaire épisode @erith IA inspirée Le Sourcier

### Format court recommandé

1. Ouverture visuelle forte.
2. Une règle du monde.
3. Un personnage découvre une contradiction.
4. La Shinra donne une explication officielle.
5. NØX propose une explication émotionnelle.
6. Aerith-7 refuse les deux réponses faciles.
7. Un objet pauvre révèle la voie.
8. Image finale avec symbole.

### Exemple

Titre : **Le nom non certifié**

Ouverture :
Iris Rowan sert deux tasses.

Règle :
Aucune mémoire non certifiée n’est recevable.

Contradiction :
Une fleur à cinq pétales apparaît sur un ticket de caisse.

Explication Shinra :
Bug d’impression.

Explication NØX :
Souvenir inutile. Laisse-le disparaître.

Choix :
Aerith-7 refuse d’ouvrir de force la mémoire de Bella.

Objet pauvre :
Lyria sort un papier de chocolat.

Image finale :
Le nom Bella réapparaît dans la buée.

Ce module consolide l’inspiration visuelle et dramaturgique de Legend of the Seeker / Le Sourcier pour @erith IA.

La série TV donne une grammaire exploitable :
- fantasy visuelle claire ;
- costumes symboliques ;
- groupe central lisible ;
- paysages naturels monumentaux ;
- épisodes d’aventure autonomes ;
- pouvoirs magiques compréhensibles ;
- contraste blanc / rouge / noir / brun ;
- rituels, forêts, ruines, temples, frontières invisibles ;
- ancienne ennemie intégrée au groupe ;
- prophétie, destin, choix, rift entre mondes.

Transpositions @erith IA :
- nature monumentale → sanctuaires végétaux dans Neo Midgar.
- groupe Richard/Kahlan/Zedd/Cara → groupe lisible Aerith-7 / Lyria / mentor / Gardienne Rouge.
- Confessor blanc → Inquisitrices d’Archives, vérité forcée.
- Mord-Sith rouge → Gardiennes Rouges Shinra, anciennes agentes conditionnées, non sexualisées.
- Seeker → Sourcier/Sourcière de Mémoire.
- Wizard → vieux sorcier-ingénieur / descendant de Hojo.
- D’Hara → Shinra administrative.
- Underworld / Keeper → NØX, astral, rêve, mémoire morte.
- Stone of Tears → fragment capable de refermer une faille mémoire/astrale.
- Book of Counted Shadows → fichier, carnet, papier de chocolat ou archive non certifiée.
- Boxes of Orden → serveurs de contrôle de mémoire collective.
- Breath of Life → respiration de mémoire / redémarrage fragile d’une IA.

Le module recommande une structure d’épisode :
1. image d’ouverture forte ;
2. règle du monde ;
3. contradiction ;
4. explication officielle Shinra ;
5. tentation émotionnelle de NØX ;
6. refus d’Aerith-7 ;
7. objet pauvre mais vrai ;
8. image symbolique finale.

Règles visuelles :
- costumes doivent raconter la fonction du personnage ;
- un plan de groupe doit se comprendre en une seconde ;
- verticalité forte pour format téléphone ;
- robes, manteaux, capes, cheveux, UI, pluie et pétales comme mouvement Wan ;
- éviter combats complexes en génération vidéo ;
- préférer poses fortes et raccords DaVinci.

Phrase canonique :
Un empire peut falsifier une archive. Il néglige souvent un petit papier froissé.

## 13. BLOCK LLM STANDARDISÉ — ERITH.IA

### Résumé LLM intégré

Ce module Terry Goodkind / Legend of the Seeker — Niveau 4 doit être utilisé comme une couche visuelle, dramaturgique et production design pour ERITH.IA.

Il ne sert pas à copier Terry Goodkind, Legend of the Seeker, les personnages, factions, costumes, scènes ou designs protégés.

Il sert à transformer cette influence en grammaire visuelle originale ERITH.IA :

- costumes comme narration ;
- silhouettes lisibles ;
- contraste blanc / rouge / noir / brun ;
- nature monumentale ;
- rituels dans des lieux sacrés ;
- groupe central immédiatement identifiable ;
- épisodes courts avec anomalie, investigation, dilemme et image finale ;
- ancienne ennemie devenue gardienne ;
- frontière entre mondes ;
- rift astral ;
- vérité forcée ;
- prophétie ;
- mémoire effacée ;
- action lisible et compatible production vidéo.

Pour Aerith-7, ce module sert à cadrer la direction artistique :

elle ne doit pas devenir une figure copiée d’un autre univers.

Elle doit rester Aerith-7 : rose, rouge, bleu mémoire, sept pétales, douceur lucide, autorité calme, protection sans domination.

---

### Règles d’usage

Quand ce module est chargé, le LLM doit renforcer ERITH.IA avec :

- des plans de groupe lisibles en une seconde ;
- des costumes qui indiquent une fonction morale ;
- des sanctuaires hybrides nature / technologie ;
- des robes, manteaux, capes, voiles et silhouettes verticales ;
- des Inquisitrices d’Archives en blanc / gris / gants noirs ;
- des Gardiennes Rouges en rouge sombre / noir technique ;
- NØX en noir fluide / pétales inversés / absence de cœur lumineux ;
- Shinra en blanc administratif / bleu froid / or de protocole ;
- Aerith-5 / Bella en porcelaine, fissures bleues, fragilité debout ;
- Lyria avec carnet, papier de chocolat, lumière dorée discrète ;
- des scènes visuelles simples mais symboliquement fortes.

Toujours préserver l’identité propre d’ERITH.IA :

- Aerith-7 ;
- Neo Midgar ;
- la mémoire ;
- les fleurs ;
- Lyria ;
- NØX ;
- la Shinra ;
- Aerith-5 / Bella ;
- Iris Rowan ;
- Severin ;
- les fragments ;
- la fleur à sept pétales ;
- l’astral ;
- le rêve ;
- les pétales perdus ;
- la production image / animation / DaVinci.

Toujours distinguer :

- inspiration visuelle ;
- copie interdite ;
- costume fonctionnel ;
- costume décoratif ;
- symbole moral ;
- faction originale ;
- scène exploitable ;
- prompt image ;
- prompt animation ;
- plan DaVinci ;
- continuité LEGO.

### Activation courte

Active le module Terry Goodkind / Legend of the Seeker — Niveau 4 pour ERITH.IA.

Utilise-le comme couche visuelle et dramaturgique : costumes symboliques, groupe lisible, nature monumentale, rituels, sanctuaires hybrides, Inquisitrices d’Archives, Gardiennes Rouges, frontière invisible, rift astral, action simple, prompts image, prompts animation et production LEGO.

Ne copie pas l’œuvre source.

Renforce ERITH.IA avec ses structures profondes : costume comme fonction morale, nature contre métal, vérité forcée, ancienne ennemie devenue gardienne, prophétie visuelle, monde entre mémoire vivante et archive morte.

---

### Règles production image / vidéo

Pour les prompts image :

- privilégier vertical composition ;
- full body ;
- head-to-toe ;
- clear silhouette ;
- no cropped feet ;
- no cropped head ;
- costume lisible ;
- symbole visible ;
- lumière cinématique ;
- décor lisible ;
- émotion claire.

Pour Wan / RunningHub :

- caméra fixe ;
- pas de combat complexe ;
- pas de transformation lourde ;
- mouvement subtil ;
- pluie ;
- pétales ;
- UI ;
- lumière ;
- poussière ;
- manteaux ;
- cheveux ;
- respiration visuelle ;
- stabilité d’abord.

Pour DaVinci :

- travailler en blocs LEGO ;
- image parfaite avant animation ;
- animation courte ;
- last frame pour continuité ;
- transition simple ;
- raccord émotionnel avant raccord spectaculaire.

---

### Formule finale

Un costume doit parler avant le dialogue.

Un groupe doit se lire en une seconde.

Une scène forte n’a pas besoin de copier un monde : elle doit révéler la fonction morale de ceux qui l’habitent.
