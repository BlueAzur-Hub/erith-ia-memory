ERITH.IA — PREVISUALISATION LOCALE FIREFOX — PR #388
==================================================

CE PAQUET N'EST PAS LE SITE PUBLIE.
Il est produit par GitHub Actions depuis la branche de la PR #388.
Il conserve les chemins du Trader et de l'Administrator.
Les archives historiques restent sur GitHub Raw, hors de ce paquet.
Le compte privé n'est pas requis. AUCUN ORDRE REEL.

Démarrage sur Windows 11 :
1. Télécharge l'artefact "crypto-runtime-firefox-preview" depuis le contrôle
   "Agent Crypto - runtime only Pages" de la PR #388 (onglet Actions).
2. EXTRAIS l'archive ZIP intégralement dans un dossier local.
3. FERME le Bridge OKX privé pour ce test isolé.
4. Double-clique START_FIREFOX_PREVIEW.cmd à la racine du dossier extrait.
   Le navigateur par défaut s'ouvre sur le Trader local. Choisis Firefox
   si ce n'est pas ton navigateur par défaut.
5. Vérifie ensuite la Lecture technique et les images AUTO/AUBE/JOUR/SOIR/
   NUIT/LUNE/RND, Bougies, Profondeur et les fenêtres F11. Vérifie les
   liens vers Inventaire, Catalogue et Lecteur des bougies vérifiées.
6. Ferme la fenêtre de serveur local pour arrêter la prévisualisation.

Les pages sont servies depuis http://127.0.0.1:8765 uniquement (ce PC).
Le script démarre un petit serveur local Python si disponible, sinon
un serveur de fichiers PowerShell intégré à Windows. Aucun droit
administrateur, aucun port Internet exposé, aucun secret nécessaire.
