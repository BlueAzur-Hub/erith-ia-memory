THE PROJECT

From one LEGO set to a personal mechanical dragon.

Rising Phoenix began with LEGO set 70666, but the project quickly became a real design journey: dismantling, searching for parts, rebuilding, testing proportions, refining the rear mechanics, and pushing the machine until it had its own identity.

The physical MOC came first. BrickLink Studio came later as the technical twin: a way to reconstruct what had already been built in real bricks and turn it into reproducible instructions.

This page stays selective and visual. It shows the finished dragon first, then the path that made it possible.
