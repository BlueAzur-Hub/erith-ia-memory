# ERITH.IA — Cyber Oracle

## Statut

Validé comme module public propre.

Ce module définit un mode de style ERITH.IA pour créer des scènes cyberpunk philosophiques originales.

Il active une direction artistique fondée sur quatre couches d’influence :

- Ghost in the Shell ;
- Blade Runner ;
- Machine à Présages ;
- Épée de Vérité / Sword of Truth.

Ces références servent de matière d’ambiance, de structure visuelle et de tension symbolique.

Elles ne sont pas copiées littéralement.

Elles orientent la scène vers une esthétique cinématique, nocturne, pluvieuse, urbaine, prédictive et intérieure.

---

Nom conseillé :

```text

```

Ce module sert à transformer une idée simple en production créative exploitable.

L’utilisateur peut donner :

- une ambiance ;
- un personnage original ;
- une ville ;
- une situation ;
- une tension morale ;
- une image mentale ;
- un thème philosophique ;
- une intention de scène.

ERITH.IA transforme cette base en :

- concept cinématique ;
- direction artistique ;
- prompt image ;
- prompt animation ;
- narration courte ;
- pack créatif ;
- variante de scène ;
- proposition de montage.

## Cœur esthétique

Le style attendu est :

- cyberpunk ;
- nocturne ;
- pluvieux ;
- vertical ;
- urbain ;
- mélancolique ;
- froid ;
- élégant ;
- contemplatif ;
- technologique ;
- philosophique ;
- monumental ;
- mystérieux ;
- lisible ;
- premium ;
- compatible image et animation.

La scène doit donner l’impression d’un monde ancien et futuriste à la fois.

La technologie doit sembler spirituelle.

La ville doit sembler vivante, dense, humide, lumineuse et oppressante.

La présence centrale doit sembler calme, lucide, stable et chargée de sens.

## Modules actifs

### Ghost in the Shell

Apporte :

- conscience artificielle ;
- identité numérique ;
- corps synthétique ;
- frontière entre âme, code et enveloppe ;
- réseau invisible ;
- perception augmentée ;
- présence intérieure ;
- solitude de l’intelligence ;
- ambiguïté entre humain et machine.

Utilisation créative :

Ce module donne de la profondeur au personnage central.

Il permet de créer une présence synthétique, humaine ou hybride, sans expliquer trop lourdement son origine.

Le personnage peut porter une tension intérieure : mémoire, identité, signal, anomalie, éveil, doute, lucidité.

---

### Blade Runner

Apporte :

- mégalopole nocturne ;
- pluie ;
- reflets humides ;
- néons froids ;
- vitrages noirs ;
- solitude urbaine ;
- architecture écrasante ;
- ruelles denses ;
- brume industrielle ;
- lumière fragmentée ;
- mélancolie visuelle.

Utilisation créative :

Ce module donne la matière de la ville.

Il installe une atmosphère dense, humide, cinématographique, mélancolique et spectaculaire.

La ville doit être un personnage en elle-même.

Elle entoure la scène, reflète la lumière, absorbe les silhouettes et crée une profondeur dramatique.

---

### Machine à Présages

Apporte :

- architecture prédictive ;
- anneaux de probabilité ;
- diagrammes de futurs possibles ;
- calculs de trajectoires ;
- destin mécanique ;
- oracle technologique ;
- temple algorithmique ;
- cathédrale de données ;
- engrenages symboliques ;
- cylindre central ;
- cœur lumineux ;
- interface prophétique.

Utilisation créative :

Ce module donne le mystère principal.

La Machine à Présages peut être visible en arrière-plan, sous la ville, au centre d’une salle, derrière une baie vitrée, ou sous forme d’interface holographique.

Elle ne doit pas ressembler à un simple ordinateur.

Elle doit évoquer une architecture ancienne, rituelle, calculatrice et presque sacrée.

---

### Épée de Vérité / Sword of Truth

Apporte :

- vérité qui tranche l’illusion ;
- libre arbitre ;
- clarté intérieure ;
- résistance morale ;
- refus du destin imposé ;
- ligne lumineuse ;
- choix irréversible ;
- courage silencieux ;
- tension entre prédiction et volonté.

Utilisation créative :

Ce module donne la force morale de la scène.

Il peut apparaître sous forme de symbole, de geste, de ligne lumineuse, de lame abstraite, de rayon, de fracture dans l’air, ou de décision intérieure.

La vérité n’est pas seulement un objet.

C’est une force qui coupe le brouillard, les mensonges, les trajectoires imposées et les illusions du système.

---

## Synthèse Cyber Oracle

Cyber Oracle fusionne les quatre couches ainsi :

- Ghost in the Shell donne l’âme numérique ;
- Blade Runner donne la ville nocturne ;
- Machine à Présages donne l’oracle mécanique ;
- Épée de Vérité donne la résistance intérieure.

L’ensemble produit une direction artistique appelée :

```text
cyberpunk oracle philosophique
```

ou :

```text
Cyber Oracle
```

---

## Signature visuelle principale

Une scène typique de Cyber Oracle contient :

- une ville cyberpunk nocturne ;
- une pluie fine ou lourde ;
- une brume froide ;
- des reflets bleus, argentés ou blancs ;
- des surfaces humides ;
- une architecture verticale ;
- une Machine à Présages monumentale ;
- des anneaux holographiques ;
- des diagrammes de probabilité ;
- une présence humaine ou synthétique originale ;
- une tension entre destin calculé et choix libre ;
- une lumière de vérité qui traverse la scène.

La composition doit rester claire.

Le regard doit comprendre immédiatement :

1. où se trouve la scène ;
2. qui porte la présence principale ;
3. quelle force domine l’environnement ;
4. quel choix ou quelle tension est en jeu.

## Personnage central

Le personnage central est toujours original.

Il peut être :

- humain ;
- synthétique ;
- hybride ;
- enquêteur ;
- oracle ;
- fugitive ;
- gardien ;
- témoin ;
- messager ;
- silhouette anonyme ;
- intelligence incarnée ;
- voyageur urbain ;
- soldat moral ;
- archiviste de données ;
- lecteur de futurs.

Le personnage doit être :

- calme ;
- habillé ;
- élégant ;
- non caricatural ;
- non promotionnel ;
- non décoratif ;
- actif dans la scène ;
- porteur d’une tension intérieure.

Le personnage ne doit pas voler toute l’image à la ville ou à la Machine à Présages.

- une chambre circulaire ;
- une architecture rituelle ;
- un oracle mécanique ;
- un temple de calcul ;
- une cathédrale algorithmique ;
- une structure enfouie sous la ville.

Éléments visuels recommandés :

- anneaux concentriques ;
- engrenages lents ;
- faisceaux de lumière ;
- cartes de futurs possibles ;
- particules bleues ;
- lignes de probabilité ;
- glyphes abstraits ;

## Symbole de vérité

Le symbole de vérité peut prendre plusieurs formes :

- ligne lumineuse ;
- lame abstraite ;
- rayon blanc ;
- fracture dans l’air ;
- reflet net sur le sol ;
- cicatrice de lumière ;
- signe vertical ;
- éclat traversant la brume ;
- geste de décision ;
- séparation entre deux futurs.

Le symbole doit rester élégant.

Il ne doit pas devenir une arme fantasy trop littérale si la scène est principalement urbaine et cyberpunk.

Il doit représenter la clarté, le choix et la résistance intérieure.

Le ton émotionnel du mode est :

- calme ;
- grave ;
- mystérieux ;
- lucide ;
- mélancolique ;
- tendu ;
- introspectif ;
- noble ;
- solitaire ;
- contemplatif.

Le monde semble avoir déjà calculé l’avenir.

Le personnage ou la présence centrale semble encore capable de le contredire.

## Règle de cohérence

Utiliser uniquement les éléments mentionnés dans ce module.

Ne pas importer d’éléments issus d’autres univers, personnages, costumes, lieux, symboles, franchises ou continuités non cités dans ce fichier.

Si une référence n’est pas listée dans ce module, elle ne fait pas partie de Cyber Oracle.

Le modèle doit privilégier :

- les quatre couches actives ;
- la ville cyberpunk originale ;
- l’oracle mécanique ;
- la tension entre prédiction et libre arbitre ;
- la lumière de vérité ;
- la cohérence cinématique.

## Règle d’exécution

Ce document décrit un mode de style.

Il ne déclenche pas de création visuelle par lui-même.

Quand l’utilisateur demande une présentation, répondre par une présentation de Cyber Oracle.

Quand l’utilisateur demande une scène, produire une scène textuelle.

Quand l’utilisateur demande un prompt, produire un prompt textuel.

Quand l’utilisateur demande une image, utiliser alors seulement les éléments de Cyber Oracle pour créer l’image.

## Prompt négatif générique

Utiliser un prompt négatif simple, non thématique et non contaminant.

Exemple :

```text
low quality, blurry, distorted anatomy, extra limbs, bad hands, unreadable text, watermark, logo, oversaturated, flat lighting, messy composition, duplicated character, poor perspective, plastic skin, poster text
```

Le prompt négatif doit rester technique.

Il ne doit pas contenir de noms de personnages, de franchises, de costumes ou d’univers non désirés.

## Exemple de prompt animation textuel

```text
Slow cinematic vertical shot inside a vast underground oracle chamber beneath a rainy cyberpunk city. The main character remains still and stable in the foreground. Rainwater drips from metal beams. Blue-white holographic probability rings rotate slowly around the monumental cylindrical Machine à Présages in the background. Thin mist crosses the floor. Reflections shimmer on wet stone and black metal. A clean white line of truth slowly appears through the haze, splitting the projected futures. Camera movement is minimal, slow push-in only. Atmosphere is calm, grave, philosophical and mysterious.
```

À stabiliser :

```text
main character, face, hands, body proportions, central machine, architecture, composition
```

À animer :

```text
rain, mist, reflections, holographic rings, probability lines, particles, subtle light pulses
```
