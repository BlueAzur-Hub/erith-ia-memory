# Agent-Crypto @erith.IA — Changelog V1.1-alpha.3

Date : 2026-07-20

## Objectif

Ajouter une première couche de mémoire pédagogique et de préparation Data Collector.

## Ajouts

- Bloc `JOURNAL PÉDAGOGIQUE + DATA` dans la section Simulation.
- Bouton `Résumer ma session`.
- Export `journal pédagogique .md`.
- Export `data snapshot .json`.
- Snapshot public non sensible :
  - profil 100 € ;
  - positions simulées ;
  - logs de simulation ;
  - prix / variations BTC, ETH, SOL si Livecheck est actif.

## Règle sécurité

Le JSON exporté reste public-compatible :

- aucune clé API ;
- aucun wallet ;
- aucun compte exchange ;
- aucune seed phrase ;
- aucun ordre réel.

## Direction produit

Cette version prépare la future base locale sur PC Ryzen 7 :

- historique de marché ;
- mémoire de simulation ;
- scoring pédagogique ;
- analyse IA future.
