# Agent-Crypto @erith.IA — Memory Explorer V1.1-alpha.5

## Rôle

Lire la mémoire locale avant de construire un backend plus lourd.

## Pourquoi cette étape ?

Avant de créer une base locale Ryzen 7, il faut vérifier que les données collectées sont lisibles et utiles.

## Ce que l’explorateur lit

- snapshots enregistrés ;
- tags d’apprentissage ;
- refus de sécurité ;
- état simulé ;
- prix BTC / ETH / SOL ;
- comparaison premier / dernier.

## Ce que l’explorateur ne fait pas

- pas de conseil financier ;
- pas de prédiction certaine ;
- pas de trading réel ;
- pas de connexion exchange.

## Direction future

V1.2-local-plan pourra reprendre cette logique pour construire :

- dossier local de données ;
- JSONL durable ;
- SQLite ;
- scheduler local ;
- scoring ;
- analyse IA.
