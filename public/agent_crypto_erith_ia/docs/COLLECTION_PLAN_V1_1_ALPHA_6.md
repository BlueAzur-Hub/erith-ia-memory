# Agent-Crypto @erith.IA — Collection Plan V1.1-alpha.6

## Rôle

Guider la collecte avant la future base locale Ryzen 7.

## Pourquoi

Un snapshot seul ne suffit pas.
La mémoire devient intéressante quand elle contient plusieurs points.

## Règle

```text
1 snapshot = état
2 snapshots = comparaison
3 snapshots = début de tendance
```

## Routine recommandée

```text
Matin / début :
Livecheck
Snapshot de référence

Après test :
Mode École guidé
Snapshot après test

Plus tard :
Livecheck
Snapshot plus tard
Comparer mémoire
```

## Migration future

Cette routine servira de modèle pour :

- scheduler local ;
- JSONL durable ;
- SQLite ;
- backend Ryzen 7.
