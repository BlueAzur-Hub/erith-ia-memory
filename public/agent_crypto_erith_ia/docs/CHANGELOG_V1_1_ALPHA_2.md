# Agent-Crypto @erith.IA — Changelog V1.1-alpha.2

## Objectif

Transformer la simulation en Mode École guidé.

## Ajouts

- Bloc `MODE ÉCOLE GUIDÉ` directement dans la section Simulation.
- Boutons de test :
  - opération prudente BTC 5 € ;
  - opération trop grosse BTC 50 € ;
  - crypto interdite DOGE 5 € ;
  - remplissage plafond 30 € ;
  - dépassement plafond ;
  - reset 100 €.
- Carte de résultat lisible en français normal.
- Journal simulation plus humain.
- Formulaire manuel reclassé en mode avancé.

## Correction pédagogique

Avant :
- l’utilisateur devait deviner quoi saisir dans le formulaire.

Maintenant :
- l’utilisateur clique un test guidé ;
- l’application explique accepté/refusé/pourquoi.
