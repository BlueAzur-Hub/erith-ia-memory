PHYSICAL SECURITY LAYER

          
Ledger / clé physique / validation humaine

          

            Ledger peut servir de coffre matériel ou de validation physique future, mais ne remplace pas Kraken ni le backend sécurisé.
          

        

        Coffre, pas pilote IA
      


      

        

          Ledger
          Wallet matériel / coffre froid / validation physique possible.
          Ne doit jamais donner une liberté totale à l’IA.
        

        

          Kraken
          Exchange de référence : lecture seule d’abord, aucune clé de retrait.
          Connexion réelle plus tard, via backend privé.
        

        

          Clé physique
          Peut renforcer l’accès machine ou l’autorisation humaine.
          À préparer hors GitHub Pages.
        

        

          Interdit
          Seed phrase, clé privée, clé de retrait ou ordre réel dans le frontend public.
          Blocage permanent.
        

      


      

        Règle simple :
        L’IA peut observer et simuler. L’humain valide. Le matériel protège. Le réel reste verrouillé.
