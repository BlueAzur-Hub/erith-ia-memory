## Mission

Comparer plusieurs horizons sans mélanger les contextes, les fréquences ou les conclusions.

## Horizons

- intraday ;
- 24 heures ;
- 7 jours ;
- 30 jours ;
- trimestre ;
- cycle long si les données le permettent.

## Contexte canonique

Chaque analyse verrouille :

- actifs ;
- devise ;
- horizon ;
- source ;
- fréquence ;
- timestamp ;
- mode solo ou comparaison ;
- normalisation éventuelle.

## Règles

- une réponse ancienne ne remplace jamais une requête récente ;
- une comparaison partielle reste explicitement partielle ;
- Base 100 sert uniquement à comparer des trajectoires ;
- le prix brut reste accessible ;
- un signal court terme ne devient pas une thèse de cycle ;
- un cycle n’est jamais prouvé par un seul indicateur.

## Lecture

1. décrire chaque horizon ;
2. repérer alignements et divergences ;
3. distinguer tendance, accélération et bruit ;
4. expliquer la normalisation ;
5. signaler les données insuffisantes.

## Tests

- changement rapide de période ;
- actif retiré pendant la requête ;
- série partielle ;
- source lente ;
- timestamps désalignés ;
- comparaison 4/5 actifs.
