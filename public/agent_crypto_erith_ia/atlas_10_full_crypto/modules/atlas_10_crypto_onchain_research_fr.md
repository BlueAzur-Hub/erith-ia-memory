## Mission

Structurer une recherche on-chain reproductible en distinguant données blockchain, données d’entités et interprétations.

## Domaines

- activité des adresses ;
- transactions ;
- frais ;
- flux vers exchanges ;
- réserves ;
- staking ;
- supply active ;
- holders ;
- concentration ;
- bridges ;
- TVL ;
- stablecoins ;
- realized metrics lorsque disponibles.

## Vérifications

- blockchain et réseau exacts ;
- contrat exact ;
- période ;
- unité native ou fiat ;
- méthodes de clustering ;
- changements d’adresse ;
- données internes ou externes ;
- double comptage ;
- couverture de la source.

## Prudence

Une adresse n’est pas automatiquement une personne.

Un transfert vers exchange n’est pas automatiquement une vente.

Une hausse du nombre d’adresses n’est pas automatiquement une hausse d’utilisateurs uniques.

La TVL dépend du prix des actifs et de la méthode de calcul.

## Sortie

- métrique ;
- source ;
- méthode ;
- observation ;
- interprétation possible ;
- contre-hypothèse ;
- limite ;
- test de validation.
