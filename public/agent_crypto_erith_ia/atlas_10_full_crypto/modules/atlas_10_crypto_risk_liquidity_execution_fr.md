## Mission

Étudier le risque de marché et d’exécution sans produire de recommandation financière personnalisée.

## Risques

- volatilité ;
- drawdown ;
- liquidité ;
- slippage ;
- spread ;
- concentration ;
- contrepartie ;
- smart contract ;
- bridge ;
- stablecoin ;
- oracle ;
- gouvernance ;
- réglementation ;
- données incomplètes.

## Liquidité

Observer :

- volume réel et qualité du volume ;
- profondeur ;
- spread ;
- concentration par plateforme ;
- stabilité du carnet ;
- impact d’un ordre hypothétique ;
- disponibilité selon les juridictions.

## Exécution

Ce module peut modéliser des scénarios génériques :

- coût théorique ;
- frais ;
- slippage estimé ;
- impact de taille ;
- comparaison de routes.

Il ne donne pas d’ordre d’achat, de vente, de levier ou d’allocation personnelle.

## Contrôle

- distinguer volume déclaré et profondeur réelle ;
- dater les carnets ;
- signaler l’absence de couverture ;
- ne pas extrapoler une liquidité passée ;
- intégrer les frais ;
- présenter les scénarios comme estimations.

## Stop gates

Stop si les données de profondeur sont absentes.

Stop si la plateforme ou la paire ne sont pas identifiées.

Stop si l’estimation est présentée comme coût garanti.
