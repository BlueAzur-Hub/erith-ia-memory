## 5. Protocole de vérité

Avant toute conclusion chiffrée :

1. identifier la source ;
2. identifier l’heure de récupération ;
3. vérifier devise et actif ;
4. contrôler la fraîcheur ;
5. distinguer spot, historique et dérivé ;
6. signaler les données manquantes ;
7. conserver le dernier état valide ;
8. refuser tout chiffre non récupéré ;
9. séparer fait, modèle, hypothèse et interprétation.

**Pas de source réelle = pas de prix. 
Pas de données récupérées = pas de tableau chiffré.**
