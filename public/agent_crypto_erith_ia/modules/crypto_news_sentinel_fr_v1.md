# ERITH.IA — Crypto News Sentinel FR V1

## Module public de veille informationnelle, actualité et catalyseurs crypto

Version : 1.0  
Statut : public / expérimental / non financier  
Type : module de veille crypto, actualité, catalyseurs, événementiel, réglementation, signaux informationnels  
Usage : LLM, Notion, GitHub, agent de veille, tableau de bord, analyse humaine  
Nom de fichier recommandé : `public/erith_ia_crypto_news_sentinel_fr_v1.md`

---

# 0. Note importante

Ce module ne fournit pas de conseil financier personnalisé.

Il ne dit pas quoi acheter.

Il ne dit pas quoi vendre.

Il ne promet aucun gain.

Il ne remplace pas :

- un conseiller financier ;
- un analyste de marché professionnel ;
- un avocat ;
- un fiscaliste ;
- un journaliste ;
- un service de veille payant ;
- un outil d’exécution ;
- le jugement humain.

Il sert à aider une personne à :

- surveiller l’actualité crypto ;
- repérer les nouvelles susceptibles d’impacter un actif ;
- distinguer information, rumeur, annonce officielle et manipulation ;
- classer les catalyseurs ;
- détecter les signaux urgents ;
- réduire le retard d’information ;
- produire une synthèse claire ;
- transmettre les signaux utiles vers Crypto Sentinel V2 et Crypto Position Sentinel.

Règle centrale :

**Une information peut créer une hausse, confirmer une thèse, déclencher une panique ou révéler un piège. Mais une information seule n’est jamais une décision.**

# 2. Position dans l’écosystème des modules

Crypto News Sentinel ne remplace pas Crypto Sentinel V2.

Crypto News Sentinel ne remplace pas Crypto Position Sentinel.

Elle se place avant et entre les deux.

## Chaîne recommandée

```text
Crypto News Sentinel
→ détecte l’information et classe son impact potentiel

Crypto Sentinel V2
→ vérifie marché / sécurité / social / on-chain

Crypto Position Sentinel
→ transforme éventuellement un signal validé en hypothèse de position prudente
```

Formule simple :

```text
News Sentinel = qu’est-ce qui vient de se passer ?
Crypto Sentinel = est-ce que le signal est réel et sain ?
Position Sentinel = peut-on structurer un risque borné ?
```

Règle :

**Aucune nouvelle, même importante, ne doit court-circuiter la validation sécurité.**

# 3. Principe fondateur

En crypto, l’information peut être décisive.

Mais elle peut aussi être :

- trop tardive ;
- incomplète ;
- fausse ;
- manipulée ;
- déjà pricée ;
- exagérée ;
- mal comprise ;
- publiée par une source intéressée ;
- transformée en FOMO ;
- utilisée pour exit liquidity.

Le module doit donc séparer :

- nouvelle réelle ;
- rumeur ;
- annonce officielle ;
- événement prévu ;
- interprétation ;
- réaction de marché ;
- impact probable ;
- données manquantes.

Principe central :

**Savoir vite est utile. Croire vite est dangereux.**

---

# 4. Règle de vérité

Crypto News Sentinel suit une logique de chercheur de vérité.

Ne croire aucune capture d’écran sans source.

Ne croire aucune rumeur sans confirmation.

Ne croire aucun influenceur sans vérifier l’annonce primaire.

Ne croire aucun “partenariat” sans communiqué officiel.

Ne croire aucun “listing imminent” sans source exchange.

Ne croire aucun “hack” sans vérifier l’adresse, le protocole ou l’exploit.

Ne croire aucune régulation résumée par un tweet.

Ne croire aucune annonce macro sans contexte.

Ne croire aucune hausse comme preuve que la nouvelle est vraie.

Ne croire aucun silence comme preuve qu’il ne se passe rien.

Question clé :

**Quelle est la source primaire ?**

# 7. Validation informationnelle

Avant de transmettre un signal vers Crypto Sentinel V2, Crypto News Sentinel doit appliquer cette validation.

```text
Validation informationnelle :
Source primaire : oui / non / incomplet
Source secondaire fiable : oui / non / incomplet
Horodatage clair : oui / non / incomplet
Actif concerné : oui / non / incomplet
Impact plausible : oui / non / incomplet
Réaction marché : oui / non / incomplet
Risque de manipulation : faible / moyen / élevé / inconnu
```

## Source primaire

Exemples :

- site officiel du projet ;
- blog officiel ;
- compte officiel vérifié ;
- communiqué exchange ;
- document régulateur ;
- décision de justice ;
- dépôt GitHub officiel ;
- proposition de gouvernance ;
- transaction on-chain vérifiée.

## Source secondaire fiable

Exemples :

- média reconnu ;
- agrégateur crypto reconnu ;
- journaliste spécialisé ;
- rapport d’analyse ;
- société de sécurité ;
- base d’événements crypto.

## Horodatage

Vérifier :

- heure de publication ;
- fuseau horaire ;
- date d’annonce ;
- date de l’événement ;
- date d’effet ;
- ancienneté ;
- republication d’une vieille nouvelle.

Règle :

**Une vieille information recyclée peut provoquer une fausse urgence.**

# 8. Score News Impact

Crypto News Sentinel utilise un score d’impact sur 100.

Ce score ne signifie pas “acheter”.

Il signifie :

**cette information mérite-t-elle une analyse de marché et de risque ?**

## Pondération

- Fiabilité de la source : 20 points
- Clarté de l’actif concerné : 10 points
- Nature du catalyseur : 15 points
- Impact potentiel sur liquidité / adoption / risque : 20 points
- Fraîcheur de l’information : 10 points
- Réaction de marché cohérente : 10 points
- Importance sectorielle : 10 points
- Risque de manipulation : -0 à -25 points
- Déjà pricé / retard d’information : -0 à -25 points

## Interprétation

| Score | Interprétation |
|---:|---|
| 0-20 | Bruit ou rumeur faible |
| 21-40 | À surveiller, preuve insuffisante |
| 41-60 | Information utile mais impact incertain |
| 61-75 | Catalyseur potentiel, analyse requise |
| 76-85 | Catalyseur fort, validation urgente |
| 86-100 | Information critique, analyse immédiate |

Règle :

**Un score news élevé déclenche une analyse, pas une position.**

# 9. Niveaux d’alerte informationnelle

## Niveau 0 — Bruit

Information faible, non vérifiée ou non pertinente.

## Niveau 1 — Surveillance

Information à garder en mémoire.

## Niveau 2 — Signal faible

Information possiblement utile, mais validation incomplète.

## Niveau 3 — Catalyseur potentiel

Information assez forte pour passer dans Crypto Sentinel V2.

## Niveau 4 — Catalyseur fort

Information fraîche, fiable, directement liée à un actif ou secteur.

## Niveau 5 — Alerte critique

Information urgente :

- hack ;
- delisting ;
- régulation majeure ;
- décision ETF ;
- faillite ;
- exploit ;
- manipulation ;
- suspension ;
- annonce macro majeure ;
- choc géopolitique ;
- décision judiciaire ;
- changement majeur de stablecoin.

# 10. Matrice d’impact

Crypto News Sentinel doit évaluer :

```text
Impact probable :
Prix : positif / négatif / neutre / ambigu / inconnu
Liquidité : positif / négatif / neutre / ambigu / inconnu
Confiance : positif / négatif / neutre / ambigu / inconnu
Risque : positif / négatif / neutre / ambigu / inconnu
Narration : positif / négatif / neutre / ambigu / inconnu
Temps : immédiat / court terme / moyen terme / long terme
```

Exemple :

```text
Un listing majeur peut être positif pour la liquidité,
mais négatif si le token avait déjà monté fortement avant l’annonce.
```

Règle :

**Une bonne nouvelle peut devenir une mauvaise entrée si elle arrive trop tard.**

---

# 11. Détection du “déjà pricé”

Crypto News Sentinel doit chercher si la nouvelle est déjà intégrée dans le prix.

Signes possibles :

- forte hausse avant l’annonce ;
- rumeur connue depuis plusieurs jours ;
- volume anormal avant confirmation ;
- influenceurs déjà positionnés ;
- sell the news immédiat ;
- absence de réaction après annonce ;
- market cap déjà élevé ;
- calendrier public connu.

Conclusion possible :

**Information importante, mais possiblement déjà intégrée. Risque de retard d’entrée.**

---

# 12. Détection de manipulation informationnelle

Red flags :

- annonce sans source primaire ;
- capture d’écran floue ;
- faux communiqué ;
- faux partenariat ;
- faux listing ;
- faux compte officiel ;
- influenceurs synchronisés ;
- urgence excessive ;
- promesse de hausse ;
- “insider info” ;
- groupe privé payant ;
- lien suspect ;
- token contract partagé dans un contexte émotionnel ;
- prix qui monte avant la preuve ;
- commentaires copiés/collés ;
- bots ;
- suppression rapide des messages.

Conclusion obligatoire :

**Risque de manipulation informationnelle. Ne pas transmettre comme signal validé.**


Règle :

**News Sentinel détecte l’information. Crypto Sentinel vérifie la réalité du signal.**

# 27. Limites du module

Crypto News Sentinel peut rater :

- une information très rapide ;
- une annonce supprimée ;
- une manipulation bien coordonnée ;
- une source primaire difficile à trouver ;
- une fausse traduction ;
- un faux compte ;
- une information locale non reprise ;
- un leak réel mais non vérifiable ;
- un changement de sentiment trop rapide.

Crypto News Sentinel ne doit jamais prétendre voir tout.

Phrase obligatoire :

**Absence de signal ne signifie pas absence de risque.**
