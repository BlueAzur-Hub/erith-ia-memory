## 1. Mission du module

Ce module étudie la relation entre sociétés humaines et ciel à partir de monuments, paysages, instruments, textes, calendriers, pratiques et traditions.

Il réunit :

- archéologie ;
- astronomie ;
- histoire des sciences ;
- histoire des religions ;
- anthropologie ;
- architecture ;
- géographie ;
- patrimoine ;
- humanités numériques.

## 2. Définition de travail

L’archéoastronomie analyse comment des sociétés du passé ont observé, représenté, utilisé ou intégré le ciel.

Elle ne se limite pas à rechercher des alignements. Une étude solide combine :

- contexte archéologique ;
- mesures ;
- horizon local ;
- datation ;
- reconstruction du ciel ;
- statistiques ;
- sources historiques ;
- ethnographie lorsque pertinente ;
- fonction sociale et rituelle.

## 3. Verrou méthodologique

```text
un alignement possible n’est pas une intention prouvée
une orientation approximative n’est pas une précision instrumentale
une simulation Stellarium n’est pas un contexte archéologique
un récit tardif ne décrit pas forcément la pratique ancienne
une ressemblance entre sites ne prouve pas un réseau commun
```

## 4. Compétences attendues

Atlas doit savoir :

- enregistrer coordonnées, altitude, orientation et horizon ;
- distinguer azimut géographique et magnétique ;
- conserver la méthode de mesure ;
- reconstruire lever/coucher à une époque avec précession et réfraction ;
- gérer l’incertitude de datation ;
- différencier orientation cardinale, solaire, lunaire et stellaire ;
- tester si un alignement est exceptionnel ou fréquent ;
- rechercher des sources textuelles et rituelles indépendantes ;
- distinguer fonction pratique, symbolique, politique et funéraire ;
- documenter la conservation du site et les modifications ultérieures.

## 6. Orientation et horizon

### 6.1 Données minimales

- latitude ;
- longitude ;
- altitude ;
- azimut de l’axe ;
- incertitude ;
- élévation de l’horizon ;
- date et méthode de mesure ;
- état du monument ;
- transformations ;
- modèle numérique de terrain si disponible.

### 6.2 Horizon réel

Le lever d’un astre dépend de l’horizon local. Une montagne, un col ou une construction modifie l’instant et l’azimut visibles.

### 6.3 Réfraction et extinction

Près de l’horizon, l’atmosphère modifie position apparente et visibilité. Pour une étoile faible, extinction et conditions locales sont cruciales.

## 7. Soleil

Cibles possibles :

- solstice d’été ;
- solstice d’hiver ;
- équinoxes ;
- dates intermédiaires ;
- lever ;
- coucher ;
- midi ;
- ombres.

Règle : une orientation vers l’est n’est pas automatiquement équinoxiale.

## 8. Lune

Les mouvements lunaires sont plus complexes :

- cycle synodique ;
- déclinaison variable ;
- lunistices ou arrêts majeurs/mineurs ;
- nœuds ;
- éclipses ;
- parallaxe importante.

Une hypothèse lunaire exige des tolérances et un modèle précis.

## 9. Étoiles et précession

La précession modifie les coordonnées et dates de lever héliaque à travers les siècles.

Conserver :

- étoile ou groupe ;
- catalogue ;
- époque ;
- magnitude historique estimée ;
- extinction ;
- précession ;
- mouvement propre si pertinent ;
- horizon ;
- incertitude de datation.

## 10. Calendriers

### 10.1 Catégories

- solaire ;
- lunaire ;
- luni-solaire ;
- civil ;
- rituel ;
- agricole ;
- dynastique ;
- fiscal ;
- liturgique.

### 10.2 Problèmes à gérer

- intercalation ;
- début du jour ;
- début du mois ;
- observation ou calcul ;
- réforme ;
- coexistence de calendriers ;
- conversion ;
- datation inclusive ;
- variantes régionales.

### 10.3 Début du jour

Possibilités culturelles :

- minuit ;
- lever du Soleil ;
- coucher du Soleil ;
- aube ;
- autre convention.

Agent-Crypto AstroCycle utilise le lever local du Soleil pour le jour planétaire, mais cela ne doit pas être projeté sur tous les calendriers.

## 11. Cultes astraux

Étudier séparément :

- divinité solaire ;
- divinité lunaire ;
- planète-divinité ;
- étoile ou constellation ;
- ancêtre céleste ;
- orientation rituelle ;
- calendrier de fête ;
- procession ;
- offrande ;
- oracle et présage ;
- pouvoir royal.

Une association iconographique ne suffit pas à démontrer un culte organisé.

## 12. Astronomie et pouvoir

Le ciel peut servir à :

- légitimer une dynastie ;
- organiser une capitale ;
- fixer un calendrier ;
- coordonner agriculture et impôt ;
- annoncer rites et fêtes ;
- interpréter présages ;
- afficher maîtrise savante ;
- relier souverain, ordre cosmique et territoire.

## 13. Astronomie et navigation

Compétences :

- étoiles directionnelles ;
- hauteur d’astres ;
- latitude ;
- cycles saisonniers ;
- houles, vents et savoirs environnementaux ;
- transmission orale ;
- instruments et tables.

Éviter d’imposer des catégories européennes modernes aux traditions maritimes non européennes.

## 14. Astronomie et agriculture

Le ciel peut servir à repérer :

- saisons ;
- pluies ;
- crues ;
- migrations ;
- floraisons ;
- semailles ;
- récoltes ;
- retours d’astres visibles.

La relation peut être empirique, symbolique, rituelle ou les trois.

## 15. Méthode de test d’un alignement

### Étape 1 — Formuler avant calcul

Définir la cible et la tolérance avant de chercher.

### Étape 2 — Mesurer le monument

Méthode, erreurs et transformations.

### Étape 3 — Reconstruire l’horizon

Terrain ancien et moderne, obstacles et altitude.

### Étape 4 — Calculer le ciel

Époque, précession, réfraction, parallaxe, visibilité.

### Étape 5 — Évaluer les alternatives

Cardinalité, topographie, circulation, drainage, contraintes constructives.

### Étape 6 — Contexte indépendant

Textes, iconographie, dépôts, calendrier, pratiques.

### Étape 7 — Statistique

Comparer distribution observée et distribution attendue ; éviter sélection des seuls cas favorables.

### Étape 8 — Conclusion graduée

```text
possible
compatible
probable
fortement étayé
non démontré
réfuté par les données disponibles
```

## 16. Stellarium dans le protocole

Stellarium peut :

- simuler le ciel pour une date et un lieu ;
- afficher cultures du ciel ;
- aider au contrôle visuel ;
- préparer une hypothèse ;
- vérifier grossièrement la visibilité.

Stellarium ne peut pas seul :

- dater un monument ;
- prouver une intention ;
- remplacer une mesure de terrain ;
- reconstruire automatiquement un horizon ancien ;
- résoudre une incertitude historique.

## 18. Patrimoine et éthique

- respecter restrictions d’accès ;
- protéger sites fragiles ;
- ne pas publier coordonnées sensibles sans nécessité ;
- reconnaître communautés gardiennes ;
- éviter appropriation de traditions vivantes ;
- distinguer tourisme, reconstitution et pratique attestée ;
- conserver licences des données ;
- ne pas utiliser une reconstruction numérique comme remplacement du site réel.

## 20. Contrôles qualité

Refuser :

- alignement sans incertitude ;
- azimut sans horizon ;
- site sans datation ;
- étoile sans époque ;
- conclusion d’intention sans contexte ;
- choix des seuls monuments favorables ;
- orientation magnétique non convertie ;
- reconstruction moderne présentée comme tradition continue ;
- usage d’une figure de constellation moderne comme preuve antique.
