# Pack — ERITH.IA Yohan Crypto Auto-Agent FR V1.1

Ce pack contient le fichier maître :

```text
erith_ia_yohan_crypto_auto_agent_fr_v1_1.md
```

## Nouveauté V1.1

Cette version ajoute le mode résultats chiffrés :

```text
/market
/prix BTC ETH SOL
/top 20
/watchlist
/movers
/newlistings
```

## Important

Le fichier ne contient pas les prix en temps réel.

Pour obtenir des prix actuels, le LLM doit avoir accès :
- au web ;
- ou à une API ;
- ou à un export de données.

Règle :

```text
Pas de données live, pas de prix inventés.
```

## Utilisation simple dans ChatGPT

1. Joindre le fichier `.md`.
2. Coller :

```text
Lis le fichier joint et active ERITH.IA — Yohan Crypto Auto-Agent FR V1.1.

Quand je demande /market, /prix, /top ou /watchlist, utilise des données web/API à jour si disponibles.
Date les données et cite les sources.
Si tu n’as pas accès aux données live, dis-le clairement et n’invente rien.
```

## Règle centrale

```text
Information → Validation → Risque → Position.
Jamais l’inverse.
```
