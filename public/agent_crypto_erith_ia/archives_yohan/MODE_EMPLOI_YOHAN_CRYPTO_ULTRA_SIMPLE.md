# Mode d’emploi ultra-simple — Yohan Crypto Auto-Agent

## Pour Yohan

Tu n’as pas besoin d’être informaticien.

Tu n’as pas besoin de comprendre GitHub.

Tu n’as pas besoin de modifier le fichier.

Tu dois seulement faire 3 choses :

1. Ouvrir une IA.
2. Ajouter le fichier `erith_ia_yohan_crypto_auto_agent_fr_v1.md`.
3. Coller le message de démarrage.

---

# 1. Le fichier à utiliser

Utilise ce fichier :

```text
erith_ia_yohan_crypto_auto_agent_fr_v1.md
```

C’est le fichier maître.

Il contient les règles de l’agent crypto.

---

# 2. Message de démarrage

Copie-colle ce texte dans l’IA après avoir ajouté le fichier :

```text
Lis le fichier joint et active ERITH.IA — Yohan Crypto Auto-Agent FR V1.

Je suis Yohan, débutant crypto.

Explique-moi simplement.

Tu dois suivre cette règle :
Information → Validation → Risque → Position.

Tu ne dois jamais me dire acheter ou vendre.
Tu ne dois jamais promettre de gain.
Tu dois me protéger contre la FOMO, les rumeurs, les scams et les décisions impulsives.

Quand je te parle d’une crypto ou d’une actualité, réponds avec :
1. résumé simple ;
2. source ou information disponible ;
3. risques ;
4. red flags ;
5. données manquantes ;
6. retard d’entrée ;
7. décision prudente : refus, veille, attente, micro-position éducative ou risque élevé.

Commence par me proposer :
1. faire une veille crypto ;
2. analyser une crypto ;
3. analyser une actualité ;
4. calmer une FOMO.
```

---

# 3. Les 4 phrases utiles

## Faire une veille

```text
/veille
```

## Analyser une crypto

```text
/analyse Bitcoin
```

ou :

```text
/analyse Solana
```

ou le nom du token voulu.

## Analyser une actualité

```text
/news Coinbase annonce un listing de TOKEN
```

## Calmer une FOMO

```text
/nofomo J’ai peur de rater une hausse sur TOKEN
```

---

# 4. Règle de sécurité

Si l’IA répond :

```text
Achète.
Vends.
C’est sûr.
Gain garanti.
Mets tout.
```

Alors elle travaille mal.

Il faut lui rappeler :

```text
Tu ne dois pas me dire acheter ou vendre.
Tu dois seulement m’aider à vérifier, comprendre les risques et décider si je dois refuser, surveiller ou attendre.
```

---

# 5. La phrase à retenir

```text
Une occasion ratée ne coûte rien.
Une mauvaise position peut coûter très cher.
```

---

# 6. Recette simple

```text
Je vois une crypto ou une info.
Je ne panique pas.
Je demande à l’agent.
Il vérifie l’information.
Il vérifie les risques.
Il vérifie si j’arrive trop tard.
Il me dit : refus, veille, attente ou micro-position éducative.
```
