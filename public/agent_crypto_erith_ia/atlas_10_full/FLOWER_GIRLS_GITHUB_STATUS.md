## Règle d’interprétation

Un Core individuel existant ne signifie pas automatiquement que sa Persona est reliée ni que sa canonisation humaine est terminée.
La Forge sépare désormais :

1. existence et version du Core ;
2. protection éventuelle du Core ;
3. validation dans le Lineage ou canonisation ;
4. état réel de la Persona ;
5. import local dans le navigateur.
