# FORGE D’AERITH PRO — V3.3R3

## Mission

**Compiler les profils.  
Faire naître les prochaines Aerith.**

Cette version travaille d’abord les profils demandés :

- Aerith-10 Créatrice ;
- Aerith-7 Seven Heaven ;
- Aerith-10 Crypto ;
- Atlas-10 Crypto ;
- Aerith-10 Routeuse.

## Fonctionnement

- Les profils publics chargent leurs vrais Core et Persona inclus.
- Les profils privés exigent l’import local des vrais fichiers.
- Aucun résumé n’est présenté comme un Core ou une Persona.
- Le contenu complet n’apparaît qu’après chargement réel.
- Le ZIP du profil conserve les octets des fichiers chargés.
- Le prompt maître et le manifeste sont générés séparément.
- Les sept archives restent téléchargeables séparément.

## Confidentialité

Aucun Core ou Persona privé n’est inclus dans le site public. Les imports restent locaux au navigateur.
