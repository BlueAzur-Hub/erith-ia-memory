# AUDIT — Forge d’Aerith Pro V2.0-alpha.1

## Changement principal

La V2 sépare deux opérations qui ne doivent pas être confondues :

1. **Conception guidée**
   - aide textuelle ;
   - proposition Core ;
   - proposition Persona ;
   - statut non canonique ;
   - relecture humaine obligatoire.

2. **Compilation**
   - import d’un Core et d’une Persona déjà canonisés ;
   - audit ;
   - assemblage ;
   - export ZIP.

## Blueprint neutre

Aerith-10 Créatrice n’est plus utilisée implicitement comme base universelle.

Le blueprint commun est construit autour de :

- identité et mission ;
- A + B → D ;
- multi-agents internes ;
- héritage Aerith-7 ;
- options Solaire et Lunaire ;
- Living Reflection Heart ;
- modules référencés ;
- Persona distincte ;
- garde-fous ;
- stop point ;
- non-duplication.

## Exemple recommandé

Aerith-10 Préceptrice est proposée comme premier exemple parce qu’elle est :

- distincte de Créatrice ;
- déjà décrite dans la lignée Flower Girls ;
- utile aux modules Histoire, Art, Religions, Philosophie et Psychologie ;
- facilement testable avec fiches, exercices, quiz et parcours.

## Sécurité

- aucun write GitHub ;
- aucun accès privé ;
- aucun Core canonique inventé ;
- suffixe `PROPOSAL` obligatoire ;
- upload manuel après validation humaine.

## Cadrages

- affiches de lignée en ratio source 2:3 avec `contain` ;
- positions focales spécifiques pour Seven, Créatrice, Solaire et Lunaire ;
- visionneuse plein écran conservée.
