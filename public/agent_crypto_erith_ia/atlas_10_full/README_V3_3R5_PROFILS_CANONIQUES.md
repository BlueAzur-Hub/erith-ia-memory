# Forge d’Aerith Pro — V3.3R5 Profils canoniques

Cette version conserve la V3.3 GitHub Sync et corrige uniquement la lecture et l’export des quatre profils de la bibliothèque :

- Aerith-7 Seven Heaven ;
- Aerith-10 Créatrice ;
- Aerith-10 Crypto ;
- Atlas-10 Crypto.

## Règle

Un profil existant utilise son vrai Core et sa vraie Persona. Aucun document de remplacement n’est généré.

- Sources publiques : chargées depuis `downloads/`.
- Sources privées : importées localement par leur nom canonique exact.
- Les octets des sources sont préservés dans les téléchargements et les ZIP.
- La génération `PROPOSAL` reste réservée à `Nouvelle Aerith`.

Aucune image, section ou navigation n’a été ajoutée ou supprimée.
