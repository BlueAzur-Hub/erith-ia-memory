# Forge d’Aerith Pro — V3.3R7 Aide création guidée

Cette version remplace la R6 fonctionnellement refusée.

## Parcours Créatrice

1. Ouvrir Aerith-10 Créatrice.
2. Étape 06 : charger `AERITH_10_CREATRICE_PACK_PRIVE_COMPLET_18_SOURCES.zip`.
3. La Forge doit afficher `18 / 18 sources reconnues`.
4. Garder `Profil complet` pour produire 24 fichiers.
5. Confirmer humainement la paire Core / Persona.
6. Étape 07 : consulter les vrais fichiers.
7. Étape 08 : contrôler la liste des 24 fichiers puis forger.

Le pack privé est livré séparément et ne doit jamais être ajouté au dépôt public.
