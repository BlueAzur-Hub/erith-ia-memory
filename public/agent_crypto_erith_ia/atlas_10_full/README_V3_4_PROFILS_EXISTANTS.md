# Forge d’Aerith Pro V3.4 — Profils existants

Cette version sépare deux états qui étaient confondus :

1. profil complet et confirmé dans le dépôt privé ;
2. contenu Core / Persona chargé localement dans le navigateur.

Un profil existant complet n’est plus bloqué à l’étape 8. L’import local reste nécessaire uniquement pour reconstruire un ZIP final contenant les fichiers privés.

## Routeuse

- Core V4 renforcé confirmé ;
- Persona V1 liée ;
- Boot V1 lié ;
- Block LLM V1 lié ;
- profil existant complet ;
- propositions Core / Persona masquées ;
- imports locaux facultatifs pour la validation du profil ;
- imports locaux obligatoires seulement pour le ZIP à huit fichiers.
