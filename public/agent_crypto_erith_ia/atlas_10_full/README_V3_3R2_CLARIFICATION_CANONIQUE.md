# FORGE D’AERITH PRO — V3.3R2 CANDIDATE LOCALE

## Nature du patch

Cette candidate locale conserve la V3.3R1 et corrige uniquement la confusion entre :

- Aerith-10 Créatrice, profil existant ;
- Créatrice Conseillère, rôle d’aide dans la Forge ;
- le profil sélectionné ;
- une nouvelle Aerith en cours de conception.

## Titre verrouillé

**Compiler les profils.**  
**Faire naître les prochaines Aerith.**

## Comportement

### Profil existant

- affiche ses chemins et ses statuts ;
- ne génère aucun fichier `PROPOSAL` ;
- attend le Core et la Persona existants ;
- exporte leurs octets sans modification.

### Nouvelle Aerith

- niveau libre ;
- Core Proposal ;
- Persona Proposal ;
- brief de validation ;
- canonisation humaine obligatoire avant le paquet final.

## Fichiers protégés

Aucun fichier du GitHub privé n’a été modifié. Cette livraison est une copie locale de test.
