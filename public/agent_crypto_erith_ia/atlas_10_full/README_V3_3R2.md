# FORGE D’AERITH PRO — V3.3R2

## Mission

**Compiler les profils.  
Faire naître les prochaines Aerith.**

Cette version conserve l’interface et les profils existants de la Forge.

Aerith-10 Créatrice reste un profil disponible et agit aussi comme **Créatrice Conseillère** dans l’Atelier.

## Fonctions

- choisir un profil Aerith existant ;
- concevoir une nouvelle Aerith ;
- préparer son Core ;
- préparer sa Persona ;
- choisir ses héritages et ses modules ;
- ajouter les fichiers du profil ;
- générer le Boot, le Block LLM, le manifeste et le paquet final.

## Utilisation

Ouvrir `index.html` dans un navigateur récent.

Les fichiers ajoutés sont traités localement dans le navigateur.
