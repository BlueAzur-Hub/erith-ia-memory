# Forge d’Aerith Pro V4.0 — Nouvelle Constellation

## Mission

Créer une nouvelle spécialité Aerith-10 à partir d’un besoin réel, vérifier qu’elle ne duplique pas une fonction existante, puis produire un dossier de proposition Core + Persona soumis à validation humaine.

## Trois portes

1. **Créer** — contrôle anti-doublon obligatoire puis Atelier en huit étapes.
2. **Consulter** — lecture du registre local de fonctions, sans ouverture automatique d’un chantier.
3. **Compléter** — import borné des fichiers réellement fournis ; aucun manque privé n’est déduit.

## Vérité d’accès

La Forge est une application statique. Elle ne lit pas automatiquement le dépôt privé, ne prétend pas le synchroniser et n’affiche aucun statut privé comme preuve.

## Exports

- Proposition : Core PROPOSAL, Persona PROPOSAL, brief de validation.
- Paquet final : disponible seulement après contrôle anti-doublon, validation humaine et import local du Core et de la Persona réellement canonisés.
