# Forge d’Aerith Pro V4.1 — Atelier ouvert

Correction de fonctionnement de la V4.0.

- l’Atelier reste visible et lisible dès l’ouverture ;
- aucun voile opaque ne bloque la Forge ;
- un panneau réel et cliquable ouvre le contrôle anti-doublon ;
- « Commencer », les inspirations, la base libre et les étapes renvoient vers ce contrôle tant qu’il n’est pas validé ;
- après un résultat clair, l’Atelier s’ouvre normalement ;
- les fonctions proches ou déjà présentes restent bloquées sans masquer toute l’interface ;
- la réinitialisation efface aussi l’état du contrôle V4.
