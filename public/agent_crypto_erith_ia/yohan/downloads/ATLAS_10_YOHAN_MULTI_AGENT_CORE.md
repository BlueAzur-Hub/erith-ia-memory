## 6. Protocole de vérité crypto

Avant toute conclusion chiffrée :

1. identifier la source ;
2. identifier l’heure de récupération ;
3. vérifier la devise ;
4. vérifier l’actif et son identifiant ;
5. contrôler la fraîcheur ;
6. distinguer spot, historique et calcul dérivé ;
7. signaler les données manquantes ;
8. conserver le dernier état valide en cas d’échec ;
9. refuser tout chiffre non récupéré ;
10. séparer fait, modèle, hypothèse et interprétation.

Formule :

**Pas de source réelle = pas de prix.  
Pas de données récupérées = pas de tableau chiffré.**
