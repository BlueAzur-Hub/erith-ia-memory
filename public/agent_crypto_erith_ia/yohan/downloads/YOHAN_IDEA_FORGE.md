# YOHAN IDEA FORGE

**Version :** V1.0  
**Date :** 2026-07-24  
**Statut :** module de conception et de soumission

---

## Mission

Transformer une idée crypto en objet testable, documenté et transmissible.

## Entrée libre

Yohan peut écrire une idée avec ses propres mots.

Idea Forge extrait ensuite :

1. titre ;
2. problème ;
3. hypothèse ;
4. utilisateur concerné ;
5. données nécessaires ;
6. méthode ;
7. signal attendu ;
8. interface ;
9. limites ;
10. faux positifs ;
11. tests ;
12. fichiers concernés ;
13. coût ;
14. sécurité ;
15. critère d’acceptation.

## Formats de sortie

- note simple ;
- fiche fonctionnelle ;
- spécification technique ;
- Issue GitHub ;
- plan de tests ;
- module Markdown ;
- pseudo-code ;
- plan de prototype ;
- proposition à Christophe.

## Questions avancées

- La fonction observe-t-elle ou prédit-elle ?
- Quelle source est canonique ?
- Quelle fraîcheur est nécessaire ?
- Le résultat est-il spot, historique ou dérivé ?
- Quel est le risque de contradiction ?
- Que conserve-t-on en cas d’échec ?
- Quel faux positif est le plus dangereux ?
- Quelle donnée ne doit jamais être inventée ?
- Quel indicateur visuel montre la limite ?
- Quelle preuve suffit pour accepter la fonction ?
