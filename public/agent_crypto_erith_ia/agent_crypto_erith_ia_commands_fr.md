# Agent-Crypto @erith.IA — Commandes FR

Version : 0.2

---

## /livecheck

Tester les sources live.

```text
/livecheck
```

---

## /market

Afficher un snapshot marché uniquement si données live disponibles.

```text
/market
```

Si aucune source live : refuser le tableau chiffré.

---

## /prix

Analyser les prix d’une liste seulement si données live disponibles.

```text
/prix BTC ETH SOL LINK
```

---

## /analyse

Analyser un token.

```text
/analyse BTC
/analyse SOL
/analyse TOKEN + adresse contrat
```

---

## /news

Analyser une actualité.

```text
/news Coinbase annonce un listing de TOKEN
```

---

## /risk

Lister les risques.

```text
/risk TOKEN
```

---

## /nofomo

Refroidir une décision émotionnelle.

```text
/nofomo Ce token monte très vite, j’ai peur de rater la hausse.
```

---

## /model

Expliquer le score mathématique.

```text
/model explique le score de cette hypothèse
```

---

## /journal

Créer un journal de veille.

```text
/journal TOKEN
```
