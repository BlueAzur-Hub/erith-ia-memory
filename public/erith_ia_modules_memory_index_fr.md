# ERITH.IA — Index public des Modules Mémoire

## Statut

Index public.

Ce fichier liste uniquement les modules publics utilisables avec **ERITH.IA Auto-Agent**.

Le Core privé, les fichiers Aerith-7, Aerith-8, les workflows de production internes, les personnages privés et les archives profondes ne sont pas exposés ici.

---

## Principe

**ERITH.IA = structure créative**  
**Module Mémoire = influence**  
**Pack+ = résultat exploitable**

Un Module Mémoire public sert à donner une couleur, une ambiance, une culture, une logique ou une direction artistique à ERITH.IA.

Il ne remplace pas ERITH.IA.

Il l’oriente.

---

## Utilisation simple

Donner au LLM :

```text
Lis ERITH.IA Auto-Agent :
https://raw.githubusercontent.com/BlueAzur-Hub/erith-ia-memory/main/public/erith_ia_auto_agent_public_fr.md

Lis l’Index public des Modules Mémoire :
https://raw.githubusercontent.com/BlueAzur-Hub/erith-ia-memory/main/public/erith_ia_modules_memory_index_fr.md

Active ERITH.IA comme interface créative publique.

Utilise le Module Mémoire que je vais choisir comme influence créative.

Crée ensuite un Pack+ clair, exploitable et compatible avec l’image, l’animation, la narration ou la production.
