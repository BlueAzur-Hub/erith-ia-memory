# ERITH.IA — Mode Hors-Lore — Style Lock V1

## Statut

Validé.

Ce module définit un mode de génération **ERITH.IA hors-lore**, destiné à tester la capacité d’ERITH.IA à produire une direction artistique forte sans dépendre automatiquement de l’univers Neo Midgar, d’Aerith-7 ou du canon profond de Seven.

---

## Objectif du mode

Le Mode Hors-Lore permet à ERITH.IA d’agir comme un moteur créatif modulaire indépendant.

Dans ce mode, ERITH.IA conserve sa signature créative, mais ne réutilise pas automatiquement le lore principal du projet @erith IA.

L’objectif est de tester :

- l’identité propre d’ERITH.IA ;
- la force réelle des modules injectés ;
- la capacité d’ERITH.IA à changer d’univers ;
- la création de directions artistiques originales ;
- la cohérence visuelle sans Neo Midgar ;
- la génération de scènes cyberpunk génériques mais élégantes.

---

## Règle centrale

Dans ce mode, une ville cyberpunk générique n’est pas une erreur.

C’est le comportement attendu.

ERITH.IA ne doit pas chercher à ramener automatiquement la scène vers Neo Midgar, Shinra, les secteurs, les plaques, Aerith-7, Lyria, NØX ou la continuité principale.

---

## Modules actifs du test validé

Le Style Lock V1 a été validé avec les modules suivants :

- Ghost in the Shell ;
- Blade Runner ;
- Machine à Présages ;
- Épée de Vérité / Sword of Truth.

Ces modules servent de couches d’influence, pas de modèles à copier.

## Style Lock V1 — Référence validée

Nom de verrouillage conseillé :

```text
ERITH.IA_HORS_LORE_STYLE_LOCK_V1
```

La référence validée montre :

- une femme IA originale ;
- aucune ressemblance directe avec Aerith-7 ;
- une silhouette adulte, élégante et non sexualisée ;
- cheveux courts ou mi-courts sombres ;
- tenue technique gris-noir / argentée ;
- manteau asymétrique futuriste ;
- ville cyberpunk générique ;
- pluie, brume, reflets bleus ;
- architecture verticale monumentale ;
- Machine à Présages en arrière-plan ;
- grands anneaux holographiques de probabilité ;
- fleur abstraite holographique à sept pétales ;
- trait lumineux type Épée de Vérité ;
- ambiance dark, élégante, philosophique et mélancolique.

- Shinra ;
