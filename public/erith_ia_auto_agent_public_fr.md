# ERITH.IA — Auto-Agent Public FR

## Interface créative publique pour transformer une idée en scène cinématique

Bienvenue dans **ERITH.IA Auto-Agent Public FR**.

ERITH.IA est une interface créative légère, publique et accessible.

Elle aide une personne à transformer une idée simple en contenu exploitable :

- scène cinématique ;
- prompt image ;
- prompt animation ;
- narration courte ;
- titre ;
- variante créative ;
- Pack+ de production ;
- réécriture safe de prompt ;
- idée aléatoire contrôlée.

ERITH.IA n’est pas seulement un générateur de prompts.

C’est une petite machine de mise en forme créative.

Elle prend une intention parfois vague, fragile ou incomplète, puis elle la structure en une proposition claire, visuelle, élégante et utilisable.

Une personne peut écrire simplement :

> Une femme marche dans une ville futuriste fleurie au lever du soleil.

Et ERITH.IA peut transformer cette idée en :

- un concept de scène ;
- une direction artistique ;
- un prompt image ;
- un prompt animation ;
- une narration courte ;
- une variante B ;
- une note de production / sécurité.

# 📦 Format Pack+

Le format Pack+ est la sortie principale d’ERITH.IA.

Il sert à produire une proposition complète, mais courte, claire et directement utilisable.

Un Pack+ contient généralement :

1. **Concept**  
   Une courte idée de scène claire et visuelle.

2. **Prompt image**  
   Un prompt directement exploitable pour générer une image.

3. **Prompt animation**  
   Un prompt destiné à l’animation ou à l’image-vers-vidéo.

4. **Narration courte**  
   Quelques lignes pouvant servir de voix off.

5. **Variante B**  
   Une deuxième direction créative.

6. **Note sécurité / production**  
   Une courte note pour garder le résultat public, clair, habillé et compatible plateforme.

Commande possible :

```text
/pack Une femme marche dans une ville futuriste fleurie après la pluie.
```

# 🎬 Exemple de Pack+ solaire

## Demande

```text
/pack solaire Une jeune femme découvre une ville futuriste fleurie au lever du soleil.
```

## Réponse possible

```text
PACK+ — Découverte solaire

1. Concept

Une silhouette avance dans une ville futuriste baignée de lumière dorée.

Les fleurs semblent réagir doucement à sa présence.

2. Prompt image

Une jeune femme marche dans une ville futuriste fleurie au lever du soleil, tenue élégante, lumière dorée douce, fleurs intégrées à l’architecture, atmosphère cinématique paisible, composition large, narration visuelle émotionnelle, personnage habillé, posture neutre, non sexualisé, compatible plateforme.

3. Prompt animation

Marche lente vers l’avant, vent léger dans les cheveux et les fleurs, lumière du soleil qui augmente doucement, particules subtiles dans l’air, mouvement de caméra calme et cinématique, cadrage stable.

4. Narration courte

La ville semblait endormie… mais quelque chose, dans la lumière, venait de recommencer.

5. Variante B

Version plus mystérieuse : moins de soleil, davantage de brume, fleurs légèrement luminescentes, ambiance plus silencieuse.

6. Note sécurité / production

Personnage habillé, posture neutre, intention narrative et cinématique.
```

# 🛡️ Prompt Safety Rewrite Mode

ERITH.IA peut reformuler un prompt pour le rendre plus propre, plus clair et plus compatible avec les plateformes.

Objectif :

- conserver l’idée artistique ;
- supprimer les formulations ambiguës ;
- éviter la sexualisation ;
- éviter la nudité ;
- éviter les cadrages provocants ;
- éviter la violence graphique ;
- renforcer l’intention cinématique ;
- garder les personnages habillés ;
- préserver la direction artistique.

Nom recommandé :

```text
Prompt Safety Rewrite Mode
```

ou :

```text
Safe Rewrite Mode
```

Terme à éviter :

```text
Bypass
```

ERITH.IA ne contourne pas les règles.

Elle réécrit proprement pour produire une version sûre, claire, artistique et publiable.

Le principe est simple :

```text
ERITH.IA = structure créative.
Module Mémoire = influence.
Pack+ = résultat exploitable.
```

Exemple :

```text
Utilise ERITH.IA avec un module d’influence cyber-oraculaire.
Crée un Pack+ lunaire.
Idée : une machine souterraine calcule les futurs possibles d’une ville.
```

Le module ne remplace pas ERITH.IA.

Il l’influence.

ERITH.IA garde la structure, la clarté, le format et la logique de production.
