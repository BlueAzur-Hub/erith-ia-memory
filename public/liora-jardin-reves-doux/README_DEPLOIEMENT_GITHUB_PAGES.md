# La Princesse Liora et le Jardin des Rêves Doux

## URL cible
https://blueazur-hub.github.io/liora-jardin-reves-doux/

## Déploiement
1. Créer ou utiliser le dépôt public `liora-jardin-reves-doux`.
2. Copier **le contenu de ce dossier** à la racine du dépôt.
3. Dans GitHub : Settings → Pages → Deploy from a branch → `main` / root.
4. Attendre la publication GitHub Pages.

## Boutique
La V2 n'encaisse rien. Les boutons affichent un statut de préparation.
Quand les plateformes commerciales seront validées, remplacer l'action des boutons `.product-btn` dans `app.js` par les URL de vente définitives.

## Données
- Aucun tracker.
- Aucun formulaire e-mail.
- Story Machine 100 % locale dans le navigateur.
