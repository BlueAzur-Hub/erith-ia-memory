SEVEN HEAVEN — MODE LOCAL BACKEND

Fichiers à placer dans :
assets/SEVEN_PORTABLE_TERMINAL/

- index.html
- seven_backend.py
- seven_local_bridge.js
- START_SEVEN_HEAVEN_LOCAL.bat

Utilisation :
double-cliquer START_SEVEN_HEAVEN_LOCAL.bat

Résultat :
Seven Heaven s’ouvre en local sur :
http://127.0.0.1:8787/index.html

Le panneau YouTube :
- charge automatiquement les derniers fichiers output
- bouton Synchroniser YouTube
- lance le script Python côté backend
- recharge les données dans le cockpit

Important :
GitHub Pages ne peut pas faire ça seul.
Le mode automatique nécessite localhost.
