# CHARLENE SALON — Application Web

## Publication propre

Cette archive contient un seul dossier prêt à publier :

```text
CHARLENE_SALON/
├── index.html
└── assets/images/
```

Place le dossier entier dans :

```text
assets/CHARLENE_SALON/
```

L’entrée de l’application est :

```text
assets/CHARLENE_SALON/index.html
```

Cette application fonctionne dans le navigateur : navigation, cadrage local, atelier d’assistance guidé et décisions conservées sur l’appareil.

Elle ne contient ni clés, ni Core, ni Persona, ni modules privés, ni données clientes. La connexion à l’assistante privée nécessite le backend séparé défini dans le contrat d’application.
