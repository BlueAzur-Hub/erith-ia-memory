# ERITH.IA — Public Creative Interface

## Statut

Dépôt public de présentation.

Ce dépôt contient la partie publique et accessible du projet **ERITH.IA**.

Il sert de vitrine légère pour montrer comment ERITH.IA peut transformer une idée simple en contenu créatif exploitable :

- scène cinématique ;
- prompt image ;
- prompt animation ;
- narration courte ;
- variante créative ;
- Pack+ de production ;
- module mémoire public ;
- aide à la création numérique.

---

## Principe

**ERITH.IA est une interface créative publique.**

Elle ne remplace pas un artiste.

Elle ne remplace pas un réalisateur.

Elle sert à aider une personne à structurer une idée, à l’amplifier proprement, puis à la transformer en scène, prompt, animation, narration ou Pack+.

Formule simple :

**Idée simple → ERITH.IA → scène exploitable**

---

## Dépôt public

Ce dépôt public contient uniquement les éléments destinés à être montrés, partagés ou utilisés comme interface créative accessible.

Il peut contenir :

- l’Auto-Agent public ERITH.IA ;
- des modules mémoire publics ;
- des exemples de Pack+ ;
- des aides de production ;
- des blocs compatibles LLM ;
- des fichiers de présentation lisibles par humain et par machine.

---

## Ce dépôt n’est pas le Core privé

Le cœur privé du projet n’est pas exposé ici.

Les éléments profonds du projet, les versions internes, les fichiers Core, les archives de travail, les workflows de production, les personnages privés et la mémoire machine complète sont conservés séparément dans un espace privé.

Ce dépôt public doit rester :

- léger ;
- clair ;
- autonome ;
- lisible ;
- partageable ;
- compatible avec une diffusion publique.
